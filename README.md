# Full Lock Android

เว็บไซต์แนะนำแอปและสร้างโปรไฟล์อยู่ที่ `index.html` ใน root ของ main รองรับ static hosting โดยคัดไฟล์สาธารณะด้วย `node tools/package-website.mjs` แล้ว publish `dist` ดูวิธีเปิดทดสอบ ข้อมูลแผนที่ และการ deploy ที่ [docs/website.md](docs/website.md)

แอป Android แบบ native ที่ย้ายตัวกรองจาก Automagic มาเป็นแอปแยก ใช้ Java 17, Android SDK 35, Gradle wrapper 8.11.1 และ AGP 8.9.1 รองรับ Android 8 ขึ้นไป

## รุ่น 0.1.12 — โปรไฟล์

เลือกโปรไฟล์จาก header หน้าตัวกรอง เพิ่ม/เปลี่ยนชื่อ/ทำสำเนา/ลบได้ ค่าปัจจุบันย้ายเป็น “โปรไฟล์เริ่มต้น” และแก้ไขแล้วบันทึกลงโปรไฟล์ที่เลือกทันที โปรไฟล์รวมราคา เส้นทางที่ต้องการและไม่ต้องการ ประเภทงาน งานเหมา สีธีม และสีข้อความ ส่วนสิทธิ์ ปุ่มลอย ความเร็วแผง ประวัติ และสถานะเริ่ม–หยุดเป็นค่ากลาง

นำเข้า/ส่งออก `.flp` (Full Lock PHANToM) แบบไม่ใช้รหัสผ่าน หากชื่อซ้ำต้องยืนยัน “ติดตั้งทับ” หรือยกเลิก ตรวจข้อมูลก่อนติดตั้ง สลับโปรไฟล์ขณะเปิดอัตโนมัติต้องยืนยัน ไม่ให้ลบโปรไฟล์สุดท้าย ข้อกำหนดไฟล์และแผนเว็บไซต์อยู่ที่ [docs/website-and-flp-plan.md](docs/website-and-flp-plan.md)

เพิ่มเส้นทางยกเว้น แถบสีหัวการ์ด ปัดสุดแล้วสั่น/เอฟเฟกต์ก่อนปล่อยนิ้วเพื่อเริ่ม แตะหยุดพร้อมยืนยัน/ยกเลิก ปุ่มลอยแบบฟองข้อความพื้นขาว/สีตามโหมดข้อความ มีแถบสีแยกประเภทงาน และปรับเวลากาง–หุบ 0.00–1.00 วินาที ค่าเริ่มต้น 0.20

แผงรายการปุ่มลอยพื้นโปร่งใส แสดงประมาณ 3.5 งานและเลื่อนดูได้ 10 งาน กาง/หุบตามค่าที่เลือก (เริ่มต้น 0.20 วินาที) การ์ดขนส่งทันทีใช้สีธีม งานล่วงหน้าใช้สีคู่ตรงข้าม เครื่องหมายถูกใหญ่ขึ้น แตะประวัติเปิดแจ้งเตือนต้นฉบับได้ หากเปิดไม่ได้จะแสดงข้อความบนหน้าจอ สั่น และเขย่ารายการ มี Dev by PHANToM ในเมนูซ้าย ไอคอนหน้าจอหลักคงสีส้มเดิม

ใช้ไอคอนใหม่จากผู้ใช้ เพิ่ม R8 สำหรับรุ่น release ตรวจลายเซ็นก่อนเปิดแอป/อ่านงาน และปิดสำรองข้อมูลประวัติ/ตั้งค่า รายละเอียดการลงนาม ข้อจำกัดการกันคัดลอก และการเก็บกุญแจอยู่ใน [docs/security.md](docs/security.md) รุ่น release ใช้กุญแจใหม่ จึงติดตั้งทับ APK debug เดิมไม่ได้

ประวัติแสดงสถานะทำงาน/ไม่ทำงาน พร้อมเหตุผลสั้น: ราคาต่ำไป / ราคาสูงไป / ต้นทางไม่ตรง / ปลายทางไม่ตรง / ประเภทงานไม่ตรง / คาดว่าเป็นงานเหมา หากไม่ผ่านหลายข้อจะแสดงคั่นด้วย / งานเหมาคาดจากฐานราคางานตรงกับรายการที่กำหนด ไม่รวมทิป ประวัติเดิมย่อเหตุผลตอนแสดงผลโดยไม่แก้ข้อมูลเก่า สถานะทำงานหมายถึงส่งคำสั่งเปิด ไม่ยืนยันว่าหน้างานเปิดสำเร็จ

- ปุ่มลอยสีตามธีม 48dp แสดงจำนวนงานยังไม่เปิดดู แตะเพื่อดู 10 งานล่าสุดและล้างจำนวนที่ยังไม่อ่าน งานใหม่พรีวิวเฉพาะรายการล่าสุด 3 วินาทีโดยไม่ล้างจำนวน หากเปิดรายการค้างไว้ งานใหม่แทรกด้านบนและรายการเก่าสุดเฟดเลื่อนลง ไม่หุบอัตโนมัติ
- ปุ่มลอย ลากและดูดเข้าขอบจอ ขยายแผงงานด้านตรงข้ามขอบ: ซ้ายขยายขวา ขวาขยายซ้าย ตัวหนาต้นทาง/ปลายทาง ประเภทงาน และราคา+ทิป มีเพียงเครื่องหมายถูกสีเขียวเมื่องานตรงเงื่อนไข ไม่แสดงเหตุผลในแผงลอย
- อ่าน/กรอง/บันทึกงานต่อเนื่องเมื่อตัวอ่านเชื่อมต่อ แม้ปิดเปิดงานอัตโนมัติ แถบเริ่ม/หยุดควบคุมเฉพาะการส่งคำสั่งเปิดอัตโนมัติ งานตรงเงื่อนไขขณะปิดยังมี ✓ แต่ไม่ส่งคำสั่งเปิด ผู้ใช้แตะรายการเพื่อเปิดเองได้
- สวิตช์ “ปุ่มลอย” อยู่เฉพาะเมนู ☰ แยกจากการเปิดงานอัตโนมัติ ปิด ปุ่มลอย แล้วยังอ่านงานและเก็บประวัติ/จำนวนงานต่อ เปิดกลับมาจำนวนเดิมยังอยู่ การเปลี่ยนสวิตช์ไม่ล้างรายการ
- แตะนอก ปุ่มลอย และแผงรายการเพื่อหุบโดยปล่อยให้แอปด้านหลังรับการแตะตามปกติ แตะรายการภายในแผงยังเปิดงานนั้นได้
- ปุ่มลอย ซ่อนใน Full Lock และ Lalamove Driver รวมถึงขณะล็อกจอ/จอดับ ข้อมูลรายการและจำนวนยังไม่อ่านอยู่ในหน่วยความจำของ service
- หน้าตั้งค่าภาษาไทย โทนส้มและการ์ดขาวอ้างอิงภาพผู้ใช้
- เมนูตรวจการทำงานแสดงรุ่นเครื่อง/Android สิทธิ์ สถานะเชื่อมต่อตัวอ่าน เวลารับแจ้งเตือน Lalamove ล่าสุด และคัดลอกข้อมูลได้ พร้อมปุ่มขอเชื่อมต่อตัวอ่านอีกครั้ง
- เมนูซ้ายสำหรับสิทธิ์อ่านแจ้งเตือน แจ้งเตือนผล แสดงเหนือแอปอื่น และหน้าข้อมูลแอป/แบตเตอรี่
- ตัวกรองช่วงราคา สูตรหักค่าธรรมเนียม พื้นที่ ประเภทเวลา และรายการราคาบล็อกงานเหมาตาม flow เดิม
- รับเฉพาะงานจาก `com.lalamove.global.driver.sea` ที่มีเส้นทาง ประเภทเวลา และราคา ไม่เก็บ/ไม่นับประกาศ GPS ongoing หรือสรุปกลุ่ม ป้องกันข้อความเดิมซ้ำใน key เดิม โดยไม่มีเวลาพักการเปิดงาน
- เรียก `contentIntent` ของแจ้งเตือนโดยตรง ไม่ดึงแถบ ไม่ลบแจ้งเตือน และไม่ปัดรับงานแทนผู้ใช้
- เก็บผลตรวจล่าสุด 30 รายการบนเครื่อง ไม่มีอินเทอร์เน็ตหรือระบบ Login/License ภายนอก

## ติดตั้งและใช้งาน

ดาวน์โหลด APK รุ่นใช้งานจริงจาก [GitHub Release ล่าสุด](https://github.com/surakiatforwork-art/Full_Lock_lala/releases/latest) รุ่นนี้ลงนามด้วยกุญแจเดียวกับ v0.1.9 และอัปเดตทับ v0.1.9 ได้ ติดตั้งทับรุ่น debug เดิมไม่ได้ หากถอนรุ่นเก่า การตั้งค่าและประวัติจะหาย และต้องอนุญาตสิทธิ์ใหม่

ผู้พัฒนา build รุ่นใช้งานจริงด้วย `./gradlew.bat :app:assembleRelease :app:lintRelease` โดยตั้งค่ากุญแจตาม `docs/security.md` ส่วน `assembleDebug` ใช้ทดสอบเท่านั้น

เปิดครั้งแรกจะพบหน้าคำแนะนำสิทธิ์: อ่านแจ้งเตือนงาน แสดงปุ่มลอย ซ่อนปุ่มเมื่อเปิด Lalamove แจ้งเตือนจาก Full Lock และทำงานเบื้องหลัง สามารถกลับมาตั้งค่าจากเมนู ☰ ได้เสมอ สวิตช์ปุ่มลอยอยู่เหนือหัวข้อสิทธิ์ ตั้งตัวกรองแล้วปัดแถบเพื่อเริ่มหรือหยุดเปิดงานอัตโนมัติ การแตะหรือปัดไม่สุดจะไม่เปลี่ยนสถานะ บางเครื่องต้องอนุญาต restricted settings ในข้อมูลแอปก่อนเปิดอ่านแจ้งเตือนเมื่อติดตั้ง APK เอง

เมนูธีมอยู่ล่างสุด เลือกสีสำเร็จรูปหรือปรับสีเอง และสลับสีข้อความขาว–ดำได้ สีใช้ร่วมกับปุ่มลอยและจำไว้เมื่อเปิดแอปใหม่ พื้นหลังการ์ดปรับตามเพื่อให้อ่านข้อความได้

## ข้อจำกัดที่ต้องทดสอบจริง

รองรับหัวข้อ `[หมวด] ต้นทาง > ปลายทาง` และข้อความที่ขึ้นต้นด้วย `ขนส่งทันที` หรือ `งานล่วงหน้า` ตามด้วยสัญลักษณ์ ฿ พร้อมจำนวนเงินเดียว เช่น `฿156.00` หรือราคางานบวกทิป เช่น `฿276.00 + ฿10.00` ตามภาพที่ผู้ใช้ยืนยัน สูตรหักค่าธรรมเนียมหักเฉพาะราคางานแล้วจึงบวกทิป รูปแบบหลายจำนวนอื่นที่ไม่ใช่สองจำนวนคั่นด้วย + จะไม่เปิด

Android อาจบล็อกการเปิด activity จากเบื้องหลัง แม้ `PendingIntent.send()` ไม่เกิด exception ประวัติจึงใช้ข้อความ “ส่งคำสั่งเปิดแล้ว” ไม่อ้างว่าหน้างานเปิดสำเร็จ และสร้างแจ้งเตือน Full Lock ให้ผู้ใช้แตะเปิดเองได้ ต้องตรวจว่า Lalamove ให้ contentIntent ที่พาไปงานเฉพาะรายการจริง ต้องอนุญาตแสดงเหนือแอปอื่นเพื่อใช้ ปุ่มลอย และอนุญาต Usage Access เพื่อซ่อนใน Driver (ซ่อนใน Full Lock ไม่ต้องใช้ Usage Access) ตรวจสถานะ Driver ประมาณทุก 750ms จึงอาจมีความหน่วงเล็กน้อย หน้าระบบหรือแอปที่บล็อก overlay อาจไม่แสดง ปุ่มลอย และไม่มีการข้ามข้อจำกัดดังกล่าว

การกันซ้ำเป็นหน่วยความจำใน service จำกัด 200 key; การรีสตาร์ต process อาจอ่านรายการเดิมอีก ต่างงานที่ Lalamove ใช้ key และข้อความเหมือนกันยังแยกจากกันไม่ได้หากไม่มีรหัสงานจริง ไม่มีเวลาพักระหว่างการเปิดต่างงานที่ผ่านเงื่อนไข

UI และการ build ตรวจด้วย emulator; ยังไม่ได้ยืนยันการทำงานครบวงจรกับ Lalamove Driver บนอุปกรณ์จริง

## ตรวจ parser

```powershell
javac -encoding UTF-8 -d app/build/parser-checks app/src/main/java/com/fulllock/app/JobParser.java tests/ParserChecks.java
java -cp app/build/parser-checks ParserChecks
```

XML ต้นฉบับถูกเก็บไว้โดยไม่แก้ไข เอกสารตัวอย่างแจ้งเตือนอยู่ใน `docs/notification-samples.md`

การเปิดจากประวัติเก็บตัวอ้างอิงแจ้งเตือนและใช้คำสั่งจริง ตรวจ key เวลาและเนื้อหาตรงกับต้นฉบับที่ยังอยู่ก่อนเปิด ไม่มีการเดาจากข้อความหรือเปิดงานใหม่แทน ประวัติก่อน v0.1.10 ที่ไม่มีตัวอ้างอิงจะแจ้งว่าเปิดไม่ได้
