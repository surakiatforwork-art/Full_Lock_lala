# Full Lock Android

แอป Android แบบ native ที่ย้ายตัวกรองจาก Automagic มาเป็นแอปแยก ใช้ Java 17, Android SDK 35, Gradle wrapper 8.11.1 และ AGP 8.9.1 รองรับ Android 8 ขึ้นไป

## รุ่น 0.1.6

ประวัติแสดงสถานะทำงาน/ไม่ทำงาน พร้อมเหตุผลสั้น: ราคาต่ำไป / ราคาสูงไป / ต้นทางไม่ตรง / ปลายทางไม่ตรง / ประเภทงานไม่ตรง / คาดว่าเป็นงานเหมา หากไม่ผ่านหลายข้อจะแสดงคั่นด้วย / งานเหมาคาดจากฐานราคางานตรงกับรายการที่กำหนด ไม่รวมทิป ประวัติเดิมย่อเหตุผลตอนแสดงผลโดยไม่แก้ข้อมูลเก่า สถานะทำงานหมายถึงส่งคำสั่งเปิด ไม่ยืนยันว่าหน้างานเปิดสำเร็จ

- FAB สีส้ม 48dp แสดงจำนวนงานยังไม่เปิดดู แตะเพื่อดู 5 งานล่าสุดและล้างจำนวนที่ยังไม่อ่าน งานใหม่พรีวิวเฉพาะรายการล่าสุด 3 วินาทีโดยไม่ล้างจำนวน หากเปิดรายการค้างไว้ งานใหม่แทรกด้านบนและรายการเก่าสุดเฟดเลื่อนลง ไม่หุบอัตโนมัติ
- FAB ลากและดูดเข้าขอบจอ ขยายแผงงานด้านตรงข้ามขอบ: ซ้ายขยายขวา ขวาขยายซ้าย ตัวหนาต้นทาง/ปลายทาง ประเภทงาน และราคา+ทิป มีเพียงเครื่องหมายถูกสีเขียวเมื่องานตรงเงื่อนไข ไม่แสดงเหตุผลในแผงลอย
- อ่าน/กรอง/บันทึกงานต่อเนื่องเมื่อตัวอ่านเชื่อมต่อ แม้ปิดเปิดงานอัตโนมัติ สวิตช์เริ่ม/หยุดควบคุมเฉพาะการส่งคำสั่งเปิดอัตโนมัติ งานตรงเงื่อนไขขณะปิดยังมี ✓ แต่ไม่ส่งคำสั่งเปิด ผู้ใช้แตะรายการเพื่อเปิดเองได้
- สวิตช์ “เปิดปุ่มลอย FAB” แยกจากการเปิดงานอัตโนมัติ ปิด FAB แล้วยังอ่านงานและเก็บประวัติ/จำนวนงานต่อ เปิดกลับมาจำนวนเดิมยังอยู่ การเปลี่ยนสวิตช์ไม่ล้างรายการ
- แตะนอก FAB และแผงรายการเพื่อหุบโดยปล่อยให้แอปด้านหลังรับการแตะตามปกติ แตะรายการภายในแผงยังเปิดงานนั้นได้
- FAB ซ่อนใน Full Lock และ Lalamove Driver รวมถึงขณะล็อกจอ/จอดับ ข้อมูลรายการและจำนวนยังไม่อ่านอยู่ในหน่วยความจำของ service
- หน้าตั้งค่าภาษาไทย โทนส้มและการ์ดขาวอ้างอิงภาพผู้ใช้
- เมนูตรวจการทำงานแสดงรุ่นเครื่อง/Android สิทธิ์ สถานะเชื่อมต่อตัวอ่าน เวลารับแจ้งเตือน Lalamove ล่าสุด และคัดลอกข้อมูลได้ พร้อมปุ่มขอเชื่อมต่อตัวอ่านอีกครั้ง
- เมนูซ้ายสำหรับสิทธิ์อ่านแจ้งเตือน แจ้งเตือนผล แสดงเหนือแอปอื่น และหน้าข้อมูลแอป/แบตเตอรี่
- ตัวกรองช่วงราคา สูตรหักค่าธรรมเนียม พื้นที่ ประเภทเวลา และรายการราคาบล็อกงานเหมาตาม flow เดิม
- รับเฉพาะงานจาก `com.lalamove.global.driver.sea` ที่มีเส้นทาง ประเภทเวลา และราคา ไม่เก็บ/ไม่นับประกาศ GPS ongoing หรือสรุปกลุ่ม ป้องกันข้อความเดิมซ้ำใน key เดิม และพักการเปิดซ้อนตามเวลาที่กำหนด
- เรียก `contentIntent` ของแจ้งเตือนโดยตรง ไม่ดึงแถบ ไม่ลบแจ้งเตือน และไม่ปัดรับงานแทนผู้ใช้
- เก็บผลตรวจล่าสุด 30 รายการบนเครื่อง ไม่มีอินเทอร์เน็ตหรือระบบ Login/License ภายนอก

## ติดตั้งและใช้งาน

Build ด้วย `./gradlew.bat :app:assembleDebug :app:lintDebug` และติดตั้ง `app/build/outputs/apk/debug/app-debug.apk` ซึ่งลงชื่อด้วย debug key เหมาะสำหรับทดสอบ

เปิดเมนู ☰ แล้วอนุญาตอ่านแจ้งเตือนให้ Full Lock, เปิดเมนูปุ่มลอยนอกแอปแล้วอนุญาตแสดงเหนือแอปอื่น และเปิด “ซ่อน FAB ใน Lalamove” เพื่ออนุญาตเข้าถึงข้อมูลการใช้งานแอป, อนุญาตแจ้งเตือนของ Full Lock สำหรับปุ่มเปิดงานสำรอง ตั้งตัวกรองแล้วอ่านงานได้ทันที กด “เริ่มเปิดงานอัตโนมัติ” เฉพาะเมื่อต้องการให้แอปเรียกเปิดงานที่ผ่านเงื่อนไขเอง บางเครื่องอาจต้องอนุญาต restricted settings ในข้อมูลแอปก่อนเปิด notification access หากติดตั้ง APK เอง

## ข้อจำกัดที่ต้องทดสอบจริง

รองรับหัวข้อ `[หมวด] ต้นทาง > ปลายทาง` และข้อความที่ขึ้นต้นด้วย `ขนส่งทันที` หรือ `งานล่วงหน้า` ตามด้วยสัญลักษณ์ ฿ พร้อมจำนวนเงินเดียว เช่น `฿156.00` หรือราคางานบวกทิป เช่น `฿276.00 + ฿10.00` ตามภาพที่ผู้ใช้ยืนยัน สูตรหักค่าธรรมเนียมหักเฉพาะราคางานแล้วจึงบวกทิป รูปแบบหลายจำนวนอื่นที่ไม่ใช่สองจำนวนคั่นด้วย + จะไม่เปิด

Android อาจบล็อกการเปิด activity จากเบื้องหลัง แม้ `PendingIntent.send()` ไม่เกิด exception ประวัติจึงใช้ข้อความ “ส่งคำสั่งเปิดแล้ว” ไม่อ้างว่าหน้างานเปิดสำเร็จ และสร้างแจ้งเตือน Full Lock ให้ผู้ใช้แตะเปิดเองได้ ต้องตรวจว่า Lalamove ให้ contentIntent ที่พาไปงานเฉพาะรายการจริง ต้องอนุญาตแสดงเหนือแอปอื่นเพื่อใช้ FAB และอนุญาต Usage Access เพื่อซ่อนใน Driver (ซ่อนใน Full Lock ไม่ต้องใช้ Usage Access) ตรวจสถานะ Driver ประมาณทุก 750ms จึงอาจมีความหน่วงเล็กน้อย หน้าระบบหรือแอปที่บล็อก overlay อาจไม่แสดง FAB และไม่มีการข้ามข้อจำกัดดังกล่าว

การกันซ้ำเป็นหน่วยความจำใน service จำกัด 200 key; การรีสตาร์ต process อาจอ่านรายการเดิมอีก ต่างงานที่ Lalamove ใช้ key และข้อความเหมือนกันยังแยกจากกันไม่ได้หากไม่มีรหัสงานจริง เวลาพักเปิดซ้อนเริ่มที่การส่งคำสั่ง ไม่ใช่การยืนยันรับงาน และไม่คิวงานที่ข้ามระหว่างพัก

UI และการ build ตรวจด้วย emulator; ยังไม่ได้ยืนยันการทำงานครบวงจรกับ Lalamove Driver บนอุปกรณ์จริง
