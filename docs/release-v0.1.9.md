# Full Lock v0.1.9

รุ่นใช้งานจริงสำหรับ Android 8 ขึ้นไป ดาวน์โหลดไฟล์ **FullLock-v0.1.9.apk** ด้านล่าง

## การติดตั้งจากรุ่นทดสอบเดิม

รุ่นนี้ใช้กุญแจลงนามเฉพาะแทนกุญแจ debug ของรุ่นก่อน จึงติดตั้งทับรุ่นทดสอบเดิมไม่ได้ ต้องจดการตั้งค่าที่ต้องการก่อนถอนรุ่นเก่า **การถอนแอปจะลบการตั้งค่าและประวัติ** เมื่อติดตั้งรุ่นนี้แล้ว ให้เปิดแอปและอนุญาตสิทธิ์ตามคำแนะนำอีกครั้ง การอัปเดตรุ่นใช้งานจริงถัดไปจะใช้กุญแจเดียวกัน

## สิ่งที่เปลี่ยน

- ไอคอนแอปใหม่
- หน้าแนะนำสิทธิ์เมื่อเปิดครั้งแรก และรวมสิทธิ์ทั้งหมดในเมนูซ้าย
- สวิตช์ปุ่มลอยอยู่เหนือหัวข้อการอนุญาตสิทธิ์ ไม่อยู่หน้าตัวกรองหรือประวัติ
- ปัดแถบเพื่อเริ่ม/หยุดเปิดงานอัตโนมัติ การแตะหรือปัดไม่สุดไม่เปลี่ยนสถานะ
- เลือกสีแอปเองและสลับข้อความขาว–ดำได้ รวมถึงปุ่มลอย
- ใช้ข้อความสั้นและเข้าใจง่ายขึ้น
- ยกเลิกเวลาพักเปิดงาน 15 วินาที งานใหม่ที่ตรงเงื่อนไขเปิดได้ทันที
- เพิ่มการทำให้โค้ดอ่านยาก ตรวจลายเซ็น ปิดการดีบักในรุ่นแจกจ่าย และปิดการสำรองประวัติ/การตั้งค่า

แอปยังอ่านเฉพาะแจ้งเตือนงานอย่างต่อเนื่อง แม้หยุดเปิดงานอัตโนมัติหรือปิดปุ่มลอย ไม่เก็บประกาศ/GPS ongoing ผู้ใช้ยังปัดรับงานใน Lalamove Driver เอง

## การตรวจสอบ

Build release และ lint ผ่าน ทดสอบการทำงานเดิมรวม 138 ข้อผ่านบนเครื่องจำลอง ตรวจ APK ลงนาม v2/v3 และทดสอบปฏิเสธสำเนาที่เปลี่ยนลายเซ็นแล้ว การเปิดหน้างานจริงและข้อจำกัดเบื้องหลังยังขึ้นกับ Lalamove/Android และการอนุญาตบนแต่ละเครื่อง

การป้องกันช่วยเพิ่มความยากในการแกะหรือดัดแปลง ไม่รับประกันป้องกัน REA/AI หรือการคัดลอกทั้งหมด
