# Full Lock v0.1.40

- ขยายพื้นที่แตะพิกัดต้นทางด้านซ้าย–ขวา 15% และบน–ล่าง 30% โดยคงขนาดป้ายเดิมและไม่รับแตะผ่าน header ที่บังอยู่
- เพิ่มการทำโค้ดส่วนเสริมให้อ่านยากและลดข้อมูลวินิจฉัยใน log ของส่วนเสริมรุ่นใช้งานจริง
- เพิ่มการตรวจลายเซ็นรุ่นทางการก่อนเปิดแจ้งเตือนและรับคำสั่งผ่านช่องทางเชื่อมต่อ โดยไม่บล็อกเครื่องรูทหรือแอปจำลอง

## การตรวจสอบและข้อจำกัด

สร้าง release ผ่าน ตรวจลายเซ็นทางการและส่วนเสริมที่ฝังใน APK ตรวจพื้นที่แตะและการวาด 41 จุดบนแอป QA โหลดจุดเข้าโมดูล release ที่ทำโค้ดให้อ่านยากผ่าน 3 จุดโดยไม่ hook Driver ทดสอบติดตั้ง APK ที่เปลี่ยนลายเซ็นบนเครื่องจำลองแล้วแอปปฏิเสธการเปิด ตรวจผู้เรียกภายนอกถูกปฏิเสธ และ APK ลายเซ็นทางการเปิดได้ตามปกติ ตรวจไม่มีกุญแจลงนาม mapping หรือ log ติดในชุด APK

การตรวจนี้ไม่ใช่การทดสอบ hook Driver จริงครบวงจร การทำโค้ดให้อ่านยากและตรวจลายเซ็นเพิ่มต้นทุนการดัดแปลง แต่ไม่รับประกันป้องกันการแกะ การ patch ข้าม หรือการเลียนแบบได้ทั้งหมด รหัสทดสอบฟีเจอร์เดิมยังไม่ใช่ระบบสมาชิกหรือการอนุญาตจากเซิร์ฟเวอร์

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริม ไฟล์ดาวน์โหลด metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
