# Full Lock v0.1.46

- ปรับข้อความและคำแนะนำการส่งพิกัดให้ใช้ชื่อ GeoX
- แยกข้อความการเข้าสู่ระบบ ตรวจสิทธิ์ ต่ออายุ และการเชื่อมต่อ GeoX ให้ชัดเจน
- ปรับให้เปิดการเชื่อมต่อพิกัดใหม่เมื่อบริการ GeoX เปลี่ยนหลังอัปเดต
- คงการส่งพิกัดโดยไม่คัดลอกคลิบบอร์ด และอัปเดตส่วนเสริมอ่านงานเป็น 0.0.43

## การตรวจสอบ

สร้าง release ผ่าน ตรวจลายเซ็นทางการและส่วนเสริมที่ฝังตรงรุ่น ชุดทดสอบข้อความ/สมาชิก/การเชื่อมต่อผ่าน 22 ข้อ ยังไม่ได้ยืนยันการอัปเดตและการส่งพิกัดร่วมกับ GeoX รุ่นใหม่บนเครื่องรูทจริงในรอบนี้

ใช้ GeoX รุ่นที่รองรับการเชื่อมต่อ Full Lock และสิทธิ์ใช้งานที่กำหนดโดย GeoX การส่งพิกัดยังใช้ช่องทางในเครื่องตามเดิม

เผยแพร่เฉพาะไฟล์เว็บ/APK/checksum/บันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ หรือข้อมูลส่วนตัวและกุญแจลงนาม
