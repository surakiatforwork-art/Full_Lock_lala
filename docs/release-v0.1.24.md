# Full Lock v0.1.24

- นำตัวเลือกไม่รับงานเหมาออกจากแอปและหน้าสร้างโปรไฟล์บนเว็บ ให้เลือกได้จากแอป Driver โดยตรง
- ยกเลิกการบล็อกงานตามรายการราคางานเหมา แม้โปรไฟล์เดิมเคยเปิดตัวเลือกนี้ไว้
- นำเข้าโปรไฟล์เดิมได้ตามปกติ ส่งออกโดยปิดค่าเดิมเพื่อความเข้ากันได้ ไม่เปลี่ยนลำดับข้อมูลในไฟล์ .flp
- ตัวกรองราคา เส้นทาง และประเภทงานยังทำงานตามเดิม

การตรวจสอบ: FilterChecks 20, OverlayChecks 102, HistoryChecks 8 และ UiChecks 61 ผ่านบนเครื่องจำลอง พร้อมตรวจไฟล์โปรไฟล์ร่วม Java/เว็บ และ build/lint release
