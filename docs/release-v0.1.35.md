# Full Lock v0.1.35

- อัปเดตส่วนเสริมให้อัตโนมัติเมื่อเปิดแอปหลังอัปเดต หากเปิดโหมดรูทไว้และส่วนเสริมยังไม่พร้อม
- ตรวจสอบหลังติดตั้ง พร้อมปุ่มลองอีกครั้งเมื่ออัปเดตส่วนเสริมไม่สำเร็จ และเสนอรีสตาร์ตเครื่องเมื่อสำเร็จ
- เพิ่มหน้าดาวน์โหลด พร้อมเลขรุ่น วันเวลา และรายละเอียดการอัปเดต
- ชื่อไฟล์ติดตั้งมีเลขเวอร์ชัน เพื่อแยกไฟล์ใหม่ออกจากไฟล์ที่เคยดาวน์โหลด

## การตรวจสอบ

สร้าง release และตรวจลายเซ็นทางการ ตรวจหน้าดาวน์โหลดบนมือถือ ทดลองดาวน์โหลดชื่อไฟล์เลขรุ่น ตรวจ checksum ของไฟล์ทั้งสองชื่อ และผ่านการตรวจโปรไฟล์เว็บเดิม ไม่ทดสอบปัดรับงานจริง การอัปเดตส่วนเสริมอัตโนมัติยังไม่ได้ทดสอบครบวงจรบนเครื่องรูทจริงในรอบนี้

เผยแพร่เฉพาะเว็บไซต์ APK เต็มรวมส่วนเสริมภายใน metadata/checksum เครื่องมือจัดชุดเว็บ และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
