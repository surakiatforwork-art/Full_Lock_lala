# Full Lock v0.1.38

- แก้การตรวจส่วนเสริมหลังอัปเดต Full Lock ให้ตรวจใหม่หนึ่งครั้งต่อเวอร์ชันเมื่อเปิดโหมดรูทไว้ แม้เลขรุ่น Probe เท่าเดิม
- ติดตั้งส่วนเสริมใหม่เมื่อไฟล์เปลี่ยน หากไฟล์และการตั้งค่าเดิมพร้อมแล้ว แจ้งว่าเป็นรุ่นล่าสุดโดยไม่เสนอรีสตาร์ตซ้ำ
- ยังคงปุ่มลองอีกครั้งเมื่อตรวจหรือเตรียมส่วนเสริมไม่สำเร็จ และบันทึกว่าตรวจสำเร็จเฉพาะเมื่อขั้นตอนเสร็จจริง

## การตรวจสอบและข้อจำกัด

สร้าง release และตรวจลายเซ็นทางการผ่าน ผ่าน 5 จุดตรวจการตรวจซ้ำตามรุ่นแอป การลองใหม่ และรุ่น/ลายเซ็นส่วนเสริมบนแอป QA แยก ไม่ส่งคำสั่งกดหรือปัดรับงาน ยังต้องยืนยันขั้นตอนอัปเดตส่วนเสริมครบวงจรบนเครื่องรูทจริง/Virtual Master

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริม ไฟล์ดาวน์โหลด metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
