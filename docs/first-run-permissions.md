# การขอสิทธิ์ครั้งแรก

เปิดหน้าตั้งค่าของ Android อัตโนมัติทีละข้อ เฉพาะสิทธิ์ที่ยังไม่พร้อม: อ่านแจ้งเตือน ปุ่มลอย ข้อมูลการใช้งาน แจ้งเตือน Full Lock และแบตเตอรี่ ผู้ใช้ต้องอนุญาตเอง เมื่อกลับมาแอปจะไปข้อถัดไป ไม่ถามซ้ำข้อที่ปฏิเสธในรอบนั้น เก็บลำดับเมื่อหมุนหน้าจอ ไม่เปิดโหมดรับงานอัตโนมัติเอง เมื่อกดเริ่มใช้งานหรือไว้ภายหลังจะไม่เรียกขั้นตอนอัตโนมัติอีก จัดการสิทธิ์ภายหลังได้จากเมนู

ตรวจสอบ: assembleDebug, assembleDebugAndroidTest และ lintDebug ผ่าน ชุดเครื่องจำลอง Overlay 102, Filter 20, History 8 และ UI 61 ผ่าน ตรวจการเปิด Usage access อัตโนมัติ กดย้อนกลับไป Battery settings และกดย้อนกลับอีกครั้งอยู่ใน Full Lock โดยไม่วนถามซ้ำ ผ่านจาก ActivityTaskManager บน Android 35 ยังไม่ได้ตรวจโทรศัพท์แต่ละยี่ห้อ
