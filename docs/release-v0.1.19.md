# Full Lock v0.1.19 — ลากซ่อนปุ่มลอย

- ลากผีน้อยเพื่อแสดงเป้า ✕ ด้านล่างจอ เข้าใกล้เป้าจะขยาย เปลี่ยนสีและสั่นสั้น ๆ ปล่อยบนเป้าเพื่อซ่อนชั่วคราว
- สวิตช์ปุ่มลอยยังเปิด การอ่านแจ้งเตือน การเปิดงานอัตโนมัติ และจำนวนงานยังไม่อ่านคงอยู่
- ปุ่มกลับมาเมื่อมีแจ้งเตือนงานใหม่ เปิดเข้า Full Lock หรือออกจาก Driver โดยยังซ่อนใน Driver หน้าประวัติ ขณะล็อกจอ/จอดับ และเมื่อปิดสวิตช์
- ประกาศ GPS และแจ้งเตือนงานเดิมที่ซ้ำไม่ทำให้ปุ่มกลับมา
- ปล่อยนอกเป้าจะเกาะขอบจอตามเดิม ยกเลิกการลากจะกลับตำแหน่งก่อนลาก ระหว่างลากหุบแผงรายการเพื่อให้ลากทิ้งได้สะดวก
- คงขนาดผีน้อย 80 × 56dp แต่ย่อฐานสีธีมให้เล็กกว่า ตัวผีน้อยล้นพ้นฐาน พื้นที่รอบนอกโปร่งใสจริง ผีน้อยสีม่วง กล่องสีส้ม และตัวเลขบนกล่องตามเดิม

ลงนามด้วยกุญแจเดิม อัปเดตทับรุ่นใช้งานจริงได้ รองรับ Android 8 ขึ้นไป

## การตรวจสอบ

- เครื่องจำลอง Android: OverlayChecks 99, FilterChecks 7, HistoryChecks 8 และ UiChecks 57 ผ่านก่อนเพิ่มหมายเลขรุ่น
- ตรวจภาพฐานโปร่งใสและเป้าลากซ่อนแล้ว
- Build release พร้อม R8 และ lintRelease ผ่าน ตรวจลายเซ็นด้วยกุญแจเดิม
- ยังไม่ได้ทดสอบบนโทรศัพท์จริงของผู้ใช้
