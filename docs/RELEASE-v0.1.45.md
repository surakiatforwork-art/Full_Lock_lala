# Full Lock v0.1.45

- แตะป้ายพิกัดต้นทางเพื่อส่งไป PHANToM GPS โดยไม่คัดลอกลงคลิบบอร์ด แม้ส่งไม่สำเร็จก็ไม่คัดลอกแทน
- แสดงผลการส่งพิกัดและปรับคำอธิบายในเมนู
- อัปเดตส่วนเสริมอ่านงานเป็น 0.0.42

## การใช้งานร่วมกับ PHANToM GPS

ต้องใช้ PHANToM GPS รุ่นที่รองรับการเชื่อมต่อ Full Lock แบบใหม่ รุ่นที่รองรับเพียง Intent เดิมยังรับผ่านช่องทางใหม่นี้ไม่ได้ หากไม่มี PHANToM GPS ป้ายยังแสดงพิกัดได้ แต่แตะส่งหรือคัดลอกไม่ได้ตามเดิม

## การตรวจสอบ

สร้าง release ผ่าน ตรวจลายเซ็นทางการของ Full Lock และส่วนเสริมตรงกัน ตรวจส่วนเสริมที่ฝังใน APK ตรงกับไฟล์รุ่น 0.0.42 ทดสอบบนเครื่องจำลองผ่าน 19 ข้อด้านข้อมูล/ความละเอียดพิกัด/รูปแบบคำขอ และ 63 ข้อด้านป้าย/พื้นที่แตะ รวมการส่งพิกัดเต็มโดยไม่เรียกใช้คลิบบอร์ด

ยังไม่ได้ทดสอบการส่งข้ามสองแอปบนเครื่องรูทจริง การทำงานร่วมกับ HMA และความเร็วจริงในรอบนี้ ไม่มีการปัดรับงานจริง

เผยแพร่เฉพาะไฟล์เว็บ/APK/checksum/บันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ข้อมูลส่วนตัว หรือกุญแจลงนาม
