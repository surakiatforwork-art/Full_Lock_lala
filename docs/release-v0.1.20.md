# Full Lock v0.1.20 — แก้ยอดสุทธิบนปุ่มลอย

แก้ยอดสุทธิในแผงรายการและแผงงานใหม่เป็น ราคางาน − ค่าธรรมเนียมจากราคางาน + ทิป โดยไม่หักค่าธรรมเนียมจากทิป และคงชื่อเรียก “ทิป” ตามเดิม

ตัวอย่างราคา 83 บาท ทิป 7 บาท ค่าธรรมเนียม 20% ได้ 83 − 16.60 + 7 = 73.40 บาท จากเดิมแสดง 72 บาท

ตัวกรองโหมดหักค่าธรรมเนียม + ทิปใช้สูตรนี้อยู่แล้ว จึงไม่เปลี่ยนพฤติกรรมตัวกรอง

ทดสอบ ParserChecks 35 ข้อและ PanelChecks 24 ข้อผ่านบนเครื่องจำลองก่อนเพิ่มหมายเลขรุ่น Build release และ lintRelease ผ่าน ลงนามด้วยกุญแจเดิม อัปเดตทับได้
