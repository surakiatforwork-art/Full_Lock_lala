# Full Lock v0.1.44

- เปิดแสดงพิกัดต้นทางได้โดยไม่ต้องกรอกรหัส
- แตะคัดลอกพิกัดและปรับพื้นที่แตะในหน้าธีมได้เมื่อมี PHANToM GPS ติดตั้งอยู่
- เพิ่มความลื่นไหลให้พรีวิวพื้นที่แตะ โดยขนาดป้ายพิกัดคงเดิม

## การตรวจสอบ

สร้าง release และตรวจลายเซ็นทางการผ่าน ตรวจส่วนเสริมที่ฝังใน APK ตรงกับรุ่น 0.0.41 คอมไพล์ชุดทดสอบผ่าน ยังไม่ได้ยืนยันพฤติกรรมติดตั้ง/ถอน PHANToM GPS และการแตะบนหน้า Driver จริงในรอบนี้ ไม่มีการปัดรับงานจริง

เผยแพร่เฉพาะไฟล์เว็บ/APK/checksum/บันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ หรือข้อมูลส่วนตัวและกุญแจลงนาม
