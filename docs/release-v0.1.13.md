# Full Lock v0.1.13 — ปุ่มลอยผีน้อยและยอดสุทธิ

ดาวน์โหลด FullLock-v0.1.13.apk สำหรับ Android 8 ขึ้นไป ลงนามด้วยกุญแจเดิม อัปเดตทับรุ่นใช้งานจริง v0.1.9–v0.1.12 ได้โดยไม่ถอนแอป

- ปุ่มลอยผีน้อยสีม่วง กล่องสีส้ม ตัวเลขจำนวนงานอยู่บนกล่อง พื้นหลังเปลี่ยนตามธีม
- แผงงานใหม่และแผงรายการแสดงยอดสุทธิตัวหนา ก่อนเครื่องหมายถูก คำนวณ `(ราคา + ทิป) × (100 − ค่าธรรมเนียม)%` เช่น 276 + 10 บาท หัก 20% = 228.80 บาท
- เครื่องหมายถูกกระพริบประมาณ 0.75 วินาทีเมื่อเปิดแผงหรือมีรายการใหม่ แล้วติดค้าง
- เมนูซ้าย “ตั้งค่าปุ่มลอย” รวมความเร็วการกาง–หุบและสวิตช์ “แสดงรายการที่เปิดไม่ได้แล้ว” ค่าเริ่มต้นเปิด ปิดแล้วซ่อนรายการโดยไม่ลบข้อมูล
- แสดงปุ่มลอยใน Full Lock ได้ ยกเว้นหน้าประวัติงาน ยังคงซ่อนใน Lalamove Driver ขณะจอดับและล็อกจอ
- แถบหยุดทำงานใช้พื้นสีแอปและขอบสีธีม แตะแล้วมีปุ่มยืนยันด้านขวา แตะที่อื่น เปลี่ยนหน้า หรือออกจากแอปจะยกเลิกการยืนยัน โดยยังทำงานต่อ
- เลือกโปรไฟล์ผ่าน dropdown ตามธีมใต้ header พร้อมเพิ่ม จัดการ และนำเข้า สลับโปรไฟล์ระหว่างทำงานยังต้องยืนยัน

ผู้ใช้ยังปัดรับงานเองใน Driver ตามเดิม วิธีคิดราคาของตัวกรองเดิมแยกจากยอดสุทธิที่แสดงในปุ่มลอย ไฟล์โปรไฟล์ .flp ยังคงรูปแบบและข้อจำกัดเดิม
