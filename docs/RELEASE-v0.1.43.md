# Full Lock v0.1.43

- เพิ่มการปรับพื้นที่แตะป้ายพิกัดต้นทาง 100–300% ในหน้าธีม พร้อมพรีวิวกรอบเส้นประขยายทันที
- ขยายเฉพาะพื้นที่แตะ โดยขนาดป้ายเท่าเดิม ใช้ได้ทั้งหน้ารายการและหน้ารายละเอียด
- ค่าเริ่มต้น 100% เท่าขนาดป้าย และยังจำกัดพื้นที่แตะไม่ให้ล้ำ Header ที่บังป้าย

## การตรวจสอบ

สร้าง release และตรวจลายเซ็นทางการผ่าน ชุดทดสอบการวาดและสัมผัสในแอป QA แยกผ่าน 56 จุดบนเครื่องทดสอบ รวมการรับแตะนอกป้าย การบังโดย Header และค่าขอบเขต 100–300% ยังไม่ได้ยืนยันการรับสัมผัสผ่าน LSPosed บนหน้า Driver จริงรอบนี้ ไม่มีการปัดรับงานจริง ต้องใช้ส่วนเสริม 0.0.40

เผยแพร่เฉพาะไฟล์เว็บ/APK/checksum/บันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ หรือข้อมูลส่วนตัวและกุญแจลงนาม
