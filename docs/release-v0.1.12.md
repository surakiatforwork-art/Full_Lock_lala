# Full Lock v0.1.12 — โปรไฟล์ Full Lock PHANToM

ดาวน์โหลด **FullLock-v0.1.12.apk** รุ่นใช้งานจริงสำหรับ Android 8 ขึ้นไป ลงนามด้วยกุญแจเดียวกับ v0.1.9/v0.1.10 จึงอัปเดตทับได้โดยไม่ถอนแอป

## โปรไฟล์

- เลือกโปรไฟล์จาก header หน้าตัวกรอง ย้ายค่าปัจจุบันเป็น “โปรไฟล์เริ่มต้น” ให้อัตโนมัติ และเปลี่ยนชื่อนี้ได้
- เพิ่ม เปลี่ยนชื่อ ทำสำเนา ลบ นำเข้า และส่งออกได้ แก้ตัวกรองหรือสีแล้วบันทึกลงโปรไฟล์ที่เลือกทันที
- สลับขณะเปิดงานอัตโนมัติต้องยืนยัน เงื่อนไขใหม่ใช้กับงานที่เข้าหลังเปลี่ยน
- ลบโปรไฟล์ที่ใช้อยู่จะเลือกโปรไฟล์อื่นให้อัตโนมัติ ไม่ให้ลบรายการสุดท้าย
- เก็บราคา วิธีคิดราคา ค่าธรรมเนียม เส้นทางที่ต้องการ/ไม่ต้องการ ประเภทงาน งานเหมา สีธีม และสีข้อความ
- สิทธิ์ ปุ่มลอย ความเร็วแผง ประวัติ และสถานะเริ่ม–หยุดยังเป็นค่ากลางของแอป

## แบ่งปันด้วย `.flp`

`.flp` ย่อจาก **Full Lock PHANToM** เป็นไฟล์ข้อมูลไบนารีบีบอัดขนาดเล็ก ไม่ใช้รหัสผ่านและไม่รันสคริปต์ เลือกจาก header → จัดการ → ส่งออก .flp หรือ header → นำเข้า .flp

หากชื่อซ้ำ จะแสดง **“โปรไฟล์นี้มีอยู่แล้ว ต้องการติดตั้งทับหรือไม่?”** ให้เลือก **ติดตั้งทับ** หรือ **ยกเลิก** ยกเลิกแล้วข้อมูลเดิมยังอยู่ ติดตั้งทับแล้วแทนค่าทั้งชุดและเลือกโปรไฟล์นั้นใช้งาน

ไฟล์ตรวจความเสียหายและชนิด/ขอบเขตของค่าก่อนติดตั้ง ไม่เข้ารหัสและไม่ใช่ระบบป้องกันการคัดลอก พร้อมตัวสร้าง JavaScript และข้อกำหนดสำหรับเว็บไซต์ใน `docs/website-and-flp-plan.md` เว็บไซต์ยังไม่ได้เผยแพร่ในรอบนี้

## การปรับตัวกรองและปุ่มลอย

- เพิ่มเส้นทางที่ไม่ต้องการแบบกาง–หุบใต้เส้นทางที่ต้องการ ปฏิเสธก่อนแม้ตรงเงื่อนไขที่ต้องการ เช่น คลองสาม / คลองสามประเวศ
- การ์ดตัวกรองมีแถบสีธีมด้านบนและมุมมน
- ปัดเริ่มจนสุดแล้วสั่นสั้น ๆ พร้อมเอฟเฟกต์หยดน้ำ เริ่มเมื่อปล่อยนิ้ว การแตะหรือปัดไม่สุดไม่เริ่ม
- แตะหยุดแล้วต้องยืนยัน มีปุ่มยกเลิกพื้นขาว ระหว่างรอยืนยันยังทำงานต่อ
- การ์ดปุ่มลอยกว้างขึ้น เตี้ยลง พื้นขาว/พื้นตามโหมดสีข้อความ แถบสีธีมสำหรับขนส่งทันที สีคู่ตรงข้ามสำหรับงานล่วงหน้า คง ✓ สีเขียวเด่น
- เวลากาง–หุบเริ่มต้น 0.20 วินาที ปรับ 0.00–1.00 วินาทีจากเมนูซ้ายใต้ปุ่มลอย

การสั่นขึ้นกับอุปกรณ์และการตั้งค่าระบบ การเรียกเปิดงานจริงยังขึ้นกับแจ้งเตือนของ Driver และข้อจำกัด Android ผู้ใช้ยังปัดรับงานเอง

หากใช้ APK debug ก่อน v0.1.9 จะติดตั้งทับไม่ได้เพราะกุญแจต่างกัน การถอนรุ่นเก่าลบประวัติและการตั้งค่า โปรดจดค่าก่อน

ตรวจ build/lint และทดสอบรวม 287 ข้อผ่าน ตรวจการอัปเดต APK ที่ลงนามจาก v0.1.10 บนเครื่องจำลองแล้ว แนบ SHA256SUMS.txt สำหรับตรวจไฟล์ดาวน์โหลด
