# Full Lock v0.1.27

- เพิ่ม “เว้นกดงานเดิมซ้ำ” ใต้สวิตช์อ่านงานบนหน้า Driver (รูท) เลื่อนตั้งได้ 0–20 วินาที ค่าเริ่มต้น 0 คือกดซ้ำได้ทันที
- เริ่มจับเวลาหลังสั่งเปิดการ์ดสำเร็จ เว้นเฉพาะงานนั้น งานอื่นที่ตรงเงื่อนไขยังเปิดได้ ใช้รหัสงานเมื่ออ่านได้เพื่อจำงานเดิมแม้ย้ายตำแหน่งการ์ด ผู้ใช้แตะเปิดเองได้ตามเดิม
- เกณฑ์จัดอันดับประเภทการจ่ายแสดงและใช้งานเมื่อเลือกทั้งเครดิตและเงินสดเท่านั้น จำลำดับและตัวเลือกเดิมไว้เมื่อซ่อน
- เพิ่มเงา Header โดยไม่เพิ่มความสูง ยังไม่มีธีมเคลื่อนไหวหรือ 3D
- รวมตัวแก้ระยะทางและราคา/กม. ของงานส่งประหยัดที่ราคาบนการ์ดต่างจากราคาหลักในโมเดล
- บันทึกดีเลย์ในโปรไฟล์ พร้อมนำเข้า/ส่งออก FLP; โปรไฟล์เดิมและโปรไฟล์จากเว็บใช้ค่าเริ่มต้น 0

## การเผยแพร่และการทดสอบ

เผยแพร่ APK เต็มพร้อมโมดูลที่ฝังอยู่ภายใน แต่ไม่เผยแพร่ซอร์สใหม่ รวมถึงซอร์สรูท/Xposed ซอร์ส Android สาธารณะใน repo ยังเป็นรุ่นก่อนหน้า ไม่ใช่ซอร์สที่ใช้สร้าง APK รุ่นนี้ ไม่เผยแพร่ Driver APK, session, token, ผลการแกะแอป หรือกุญแจลงนาม

บิลด์ release พร้อม R8/lint และตรวจลายเซ็นทางการ app/Probe ผ่าน ตรวจโมดูลฝังตรงกับไฟล์ที่บิลด์และรูปแบบข้อมูลลับใน APK ผ่าน
ทดสอบ cooldown/payment/profile 24, bound distance 21, priority config 23, root rules 28, commission 23, panel preferences 21, visible parser 12 และ navigation 7 ผ่าน; profile codec 37/41 และ web codec 18 ผ่าน
ชุดทดสอบบน Android ในแพ็กเกจ QA แยกผ่าน: งานเดิมเปลี่ยนตำแหน่งยังเว้นเวลา, งานอื่นยังกดได้, ค่า 0, ผู้ใช้แตะเปิดเอง, slider/save, payment priority และ header elevation ใช้การ์ดจำลอง ไม่มีการกดรับงานจริง
เครื่อง ADB หลุดหลังทดสอบ ก่อนติดตั้ง APK production ล่าสุดในรอบนี้

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove ผู้ใช้ยังปัดรับงานเอง และควรตรวจเงื่อนไขของบริการที่ใช้งานร่วมกัน โหมดรูทเป็นทางเลือกที่ผู้ใช้อนุญาตเอง
