# ยอดสุทธิในปุ่มลอย

แผงงานใหม่และแผงรายการใช้ยอดสุทธิ `(ราคางาน + ทิป) × (100 − ค่าธรรมเนียมที่ตั้งไว้) / 100` ปัดเศษ HALF_UP สองตำแหน่ง ตัวอย่าง 276 + 10 บาท ค่าธรรมเนียม 20% ได้ 228.80 บาท

แสดงตัวหนา 18sp ด้านขวาของเส้นทาง ก่อนเครื่องหมายถูกสีเขียว พร้อมคงราคางานและทิปเดิมด้านล่าง ตัวเลขยาวปรับขนาดให้อยู่ในแผง ไม่ขยายความสูงการ์ด ยอดสุทธิแสดงทั้งงานตรงและไม่ตรงเงื่อนไข เครื่องหมายถูกแสดงเฉพาะงานตรงเงื่อนไข

เมื่อเปิดแผงหรือมีแถวใหม่ เครื่องหมายถูกกระพริบสามรอบรวม 750ms แล้วกลับเป็นสีเขียวค้าง ยกเลิกแอนิเมชันเมื่อ view ถูกนำออก ไม่มีการกระพริบวนไม่สิ้นสุด

ใช้ค่าธรรมเนียมจากโปรไฟล์ปัจจุบันและอัปเดตเมื่อค่านี้เปลี่ยน สูตรแสดงผลนี้แยกจากวิธีคิดราคาของตัวกรองเดิม

ตรวจสูตรด้วย ParserChecks (33 checks) รวมมีทิป ค่าธรรมเนียม 0%/100% และเศษสตางค์ Build debug/release และ lintRelease ผ่าน ชุด OverlayChecks ตรวจยอดสุทธิทั้ง preview/list ตัวหนา ขนาดตัวเลข ตำแหน่งเครื่องหมายถูก และการเปิด–หุบ/เลื่อนแผง

ผลเครื่องจำลอง emulator-5582: OverlayChecks 70, FilterChecks 7, HistoryChecks 8 และ UiChecks 48 ผ่านทั้งหมด ตรวจภาพจริงทั้งปุ่มฝั่งซ้ายและขวาแล้ว ไม่มีการติดตั้งหรือทดสอบบนโทรศัพท์ผู้ใช้ในรอบนี้
