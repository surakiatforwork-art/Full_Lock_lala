# Full Lock v0.1.42

- แก้พื้นที่แตะพิกัดที่ถูกจำกัดตามขอบชั้นวาด ให้ขยายซ้าย–ขวา 15% และบน–ล่าง 30% ตามที่กำหนด โดยไม่เปลี่ยนขนาดป้าย
- เปลี่ยนจุดดักแตะให้รองรับ Activity ที่เขียนการรับสัมผัสทับไว้ ก่อนเหตุการณ์จะไปถึงการ์ดงาน
- เมื่อแตะป้ายที่แสดงอยู่แต่ข้อมูลพิกัดเปลี่ยนแล้ว จะไม่ปล่อยการแตะให้หลุดไปเปิดการ์ดงาน และยังไม่รับแตะผ่าน header ที่บังป้าย

## การตรวจสอบและข้อจำกัด

เพิ่มกรณีทดสอบที่ชั้นวาดแคบกว่าพื้นที่รับแตะ ส่ง MotionEvent ลง–ปล่อยนอกป้ายทั้ง 4 ด้าน ตรวจว่ารับเหตุการณ์ครบ ตรวจข้อมูลพิกัดเก่า และตรวจเลือกเมธอด dispatchTouchEvent ที่ Activity เขียนทับไว้ ผ่านชุดทดสอบการวาด/สัมผัส 51 จุดบนแอป QA แยก สร้าง release และตรวจลายเซ็นทางการผ่าน

การทดสอบรอบก่อนเน้นรูปทรงพื้นที่ ไม่ครอบคลุมการส่งต่อสัมผัสใน Driver จริง รอบนี้ยังไม่มีเครื่องเชื่อมต่อให้ยืนยัน LSPosed hook บน Driver จริงครบวงจร จึงยังไม่ยืนยันผลบนอุปกรณ์ผู้ใช้ ต้องใช้ Probe 0.0.39 ใหม่ ไม่มีการเปิดหรือปัดรับงานจริง

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริม ไฟล์ดาวน์โหลด metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
