# Full Lock v0.1.47

- เพิ่มสวิตช์ “ส่งพิกัดโดยตรง” ที่หน้าธีม ในการ์ดพื้นที่แตะป้ายพิกัดต้นทาง แสดงเมื่อมี GeoX ติดตั้งอยู่
- ค่าเริ่มต้นปิด: แตะป้ายเพื่อคัดลอกพิกัด เปิดสวิตช์เพื่อส่งตรงไป GeoX โดยไม่คัดลอกซ้ำ
- การตั้งค่านี้เป็นค่าของแอป แยกจากโปรไฟล์ และไม่มีการคัดลอกสำรองหากส่งตรงล้มเหลว
- อัปเดตส่วนเสริมอ่านงานเป็น 0.0.44

## การตรวจสอบ

สร้าง release และคอมไพล์ชุดตรวจป้าย/พื้นที่แตะ/การเลือกคัดลอกหรือส่งตรงผ่าน ตรวจลายเซ็นทางการทั้งแอปและส่วนเสริม รวมไฟล์ส่วนเสริมที่ฝังใน APK ตรงรุ่น

ยังไม่ได้รันชุดตรวจการแตะที่เพิ่มในรอบนี้ เนื่องจากเครื่องจำลองยังไม่ได้รับอนุญาต ADB และไม่ได้ยืนยันบนหน้า Driver จริง ไม่มีการทดสอบปัดรับงานจริง

เผยแพร่เฉพาะไฟล์เว็บ/APK/checksum/บันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ หรือข้อมูลส่วนตัวและกุญแจลงนาม
