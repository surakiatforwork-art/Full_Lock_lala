# Full Lock v0.1.32

- เมนูด้านข้างพับส่วนตั้งค่าที่ขยายไว้เมื่อแตะหรือเริ่มเลื่อนบริเวณอื่น และนำรายการสิทธิ์ที่ซ้ำออก ใช้หน้า Permission settings แทน
- ปรับ popup และขนาดสวิตช์ เพิ่มหน้า “ตรวจสอบระบบ” พร้อมผลตรวจสีเขียว/แดง/เทา ตรวจอัปเดตทันที และลองเชื่อมบริการเดิม โดยคงการตั้งค่าที่ผู้ใช้ปิดไว้
- ปรับแท็กพื้นที่ ไอคอนการจ่าย สีเริ่มต้น และเงื่อนไขระยะไปจุดรับสูงสุด/ราคาเฉลี่ยขั้นต่ำ พร้อมรองรับโปรไฟล์เดิม
- ปรับการเปิดงานจากแจ้งเตือนในโหมดอ่านหน้า Driver การยืนยันผลเปิด และการย้อนกลับเมื่องานไม่ตรงตามเวลาที่ตั้ง
- เพิ่มภาพจำลองการปัด และตัวเลือก “ปัดรับงานอัตโนมัติ (ตรงเงื่อนไข)” ค่าเริ่มต้นปิด พร้อมยืนยันความเสี่ยงก่อนเปิด ใช้ระยะเวลา 0.01–0.50 วินาที ค่าเริ่มต้น 0.26 วินาที เมื่อเปิดภาพจำลองจะไม่ส่งคำสั่งปัดจริง

**ข้อควรทราบ:** การปัดรับงานอัตโนมัติยังไม่ได้ทดสอบรับงานจริง อาจอ่านข้อมูลหรือตำแหน่งผิดและรับงานที่ไม่ต้องการ ผู้ใช้ต้องรับผิดชอบงานที่รับตามกติกาของผู้ให้บริการ รุ่นนี้ยังไม่รับประกันการทำงานทุกเครื่องหรือทุก ROM

สำหรับโหมดอ่านหน้า Driver ให้อัปเดตส่วนเสริมตามคำแนะนำในแอป แล้วปิด Driver ให้สนิทและเปิดใหม่ อาจต้องรีสตาร์ตเครื่องหากส่วนเสริมยังไม่โหลด

## การตรวจสอบ

สร้างรุ่น release และตรวจลายเซ็นทางการของแอป/ส่วนเสริม ตรวจไฟล์ส่วนเสริมที่ฝังใน APK และยืนยันว่าไม่มีชุดคำสั่งทดสอบอุปกรณ์ติดไป ผ่านชุดทดสอบสถานะปัดอัตโนมัติ 20 ข้อ จังหวะภาพจำลอง 17 ข้อ การยืนยันเปิดงาน/ย้อนกลับ/โปรไฟล์ 66 ข้อ การย้อนกลับ 24 ข้อ และลำดับ/วิธีคิดราคา/โปรไฟล์ 23 ข้อ รวมถึงการทดสอบเงื่อนไขขอบเขตเดียวและ FLP roundtrip

หน้าตรวจสอบระบบเคยผ่านการทดสอบ UI ในแอป QA แยก 12 ข้อ การเปลี่ยน dropdown ในรอบเผยแพร่นี้ตรวจด้วยการคอมไพล์และทบทวนโค้ด ไม่ได้ติดตั้งหรือทดสอบบนอุปกรณ์ตามคำขอ และไม่มีการทดสอบปัดรับงานจริง

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริมภายใน ไฟล์ดาวน์โหลดเว็บ metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
