# Full Lock v0.1.31

- แก้แท็กพิกัดต้นทางในหน้ารายละเอียดหายหลังเปิดดูเส้นทางแล้วกดย้อนกลับ
- เก็บการผูกข้อมูลงานเฉพาะหน้า HomeOrder เดิมขณะเปิดหน้าอื่นชั่วคราว และสร้างภาพวาดใหม่เมื่อกลับมา
- ทิ้งข้อมูลที่ผูกไว้เมื่อหน้ารายละเอียดถูกทำลาย รับคำสั่งเปิดงานใหม่ หรือปิดโหมดอ่านงาน ไม่ใช้ข้อมูลนี้ข้ามไปยังหน้ารายละเอียดอีกงาน
- ไม่เพิ่มรอบสแกน การอ่านหน้าจอ หรือบริการคำนวณเส้นทาง

## การอัปเดต

เปิด Full Lock หลังติดตั้ง เพื่อให้ตรวจและอัปเดตส่วนเสริม จากนั้นปิด Driver ให้สนิทแล้วเปิดใหม่ หากส่วนเสริมยังไม่โหลด อาจต้องรีสตาร์ตเครื่อง โหมดอ่านงานบนหน้า Driver ต้องใช้รูทและ LSPosed เช่นเดิม ผู้ใช้ยังปัดรับงานเอง ไม่มีการปัดรับงานอัตโนมัติ

## การตรวจสอบ

ผ่านชุดทดสอบการกลับจากหน้าเส้นทาง การย้อนกลับอัตโนมัติ พิกัด การจัดวาง โปรไฟล์ และราคาเฉลี่ย 170 ข้อ พร้อมชุดทดสอบบน Android 34 ข้อ ซึ่งรวมการคงข้อมูลหลังล้างภาพวาด และการล้างเมื่อปิดหน้า/ปิดโหมดอ่านงาน ตรวจลายเซ็นทางการของ APK และส่วนเสริม รวมถึงไฟล์ส่วนเสริมที่ฝังใน APK แล้ว

การทดสอบวงจรกลับจากเส้นทางในรอบนี้ใช้สถานการณ์จำลองบน Android ยังไม่ได้ยืนยันกับการเปิดหน้าดูเส้นทางของ Driver จริงทุกกรณี/ทุก ROM

เผยแพร่ APK เต็มรวมส่วนเสริมภายใน พร้อมไฟล์ดาวน์โหลดเว็บและบันทึกรุ่นเท่านั้น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo เป็นรุ่นก่อนหน้า ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่เผยแพร่ Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนาม

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
