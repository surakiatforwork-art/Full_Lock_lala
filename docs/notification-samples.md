# ตัวอย่างแจ้งเตือน Lalamove Driver

## ตัวอย่าง 001 — ภาพจากผู้ใช้ วันที่ 2026-10-22

ข้อมูลนี้ถอดจากภาพ ยังไม่ได้อ่าน Android notification extras จากอุปกรณ์จริง

| ฟิลด์ | ค่าที่เห็นในภาพ |
| --- | --- |
| ชื่อแอป | Lalamove Driver |
| เวลาที่แสดง | ตอนนี้ |
| หัวข้อ | [ขนส่งสินค้า] เสาธงหิน > วังใหม่ |
| ข้อความ | ขนส่งทันที ฿156.00 รับงานขนส่ง! |
| หมวดในหัวข้อ | ขนส่งสินค้า |
| ต้นทาง | เสาธงหิน |
| ปลายทาง | วังใหม่ |
| ประเภทเวลา | ขนส่งทันที |
| จำนวนเงินที่แสดง | 156.00 THB |
| ทิป | ไม่มีข้อความทิประบุในภาพ; ยังสรุปค่าทิปจริงไม่ได้ |

## ข้อกำหนดสำหรับตัวอ่าน

- แยกหมวดในวงเล็บเหลี่ยมออกจากต้นทาง แล้วแยกเส้นทางด้วย `>` และตัดช่องว่างหัวท้าย
- เก็บข้อความดิบไว้คู่กับผลที่แยกได้ โดยตรวจ extras จริงก่อนยืนยันว่าหัวข้อและข้อความอยู่ใน EXTRA_TITLE / EXTRA_TEXT หรือ EXTRA_BIG_TEXT
- อ่านจำนวนเงินแบบทศนิยมให้ครบ: `฿156.00` ต้องได้ 156.00 ไม่ใช่การนำกลุ่มตัวเลข 156 และ 00 มาต่อหรือบวกกัน รองรับหลักพันและทิปด้วยตัวอย่างเพิ่มเติมก่อนสรุปรูปแบบ
- จำนวนเงินในภาพเป็นราคาที่แสดง ยังไม่มีหลักฐานว่าเป็นยอดก่อนหรือหลังหักค่าธรรมเนียม หรือรวมทิปหรือไม่
- หมวด `ขนส่งสินค้า` กับประเภทเวลา `ขนส่งทันที` เป็นคนละฟิลด์
- ภาพยืนยันไม่ได้ว่า contentIntent มีค่าหรือเปิดหน้างานเฉพาะรายการได้ ต้องตรวจจากแจ้งเตือนจริง
- package ที่ flow เดิมกรองคือ `com.lalamove.global.driver.sea` แต่ภาพยืนยัน package ไม่ได้
- ป้องกันประมวลผลซ้ำโดยพิจารณา notification key ร่วมกับข้อมูลอัปเดต/รหัสงานถ้ามี อย่าใช้ราคาและเส้นทางอย่างเดียว เพราะต่างงานอาจมีค่าเหมือนกัน และ key เดิมอาจถูกอัปเดต
- เป้าหมายคือเปิดแจ้งเตือนที่ตรงเงื่อนไขโดยตรง เก็บแจ้งเตือนไว้ และให้ผู้ใช้ปัดรับงานเอง

## สิ่งที่ยังต้องมีตัวอย่าง

งานล่วงหน้า, ราคามีคอมมาหลักพัน, งานหลายจุด, แจ้งเตือนอัปเดตและแจ้งเตือนกลุ่ม รวมถึงข้อมูล extras และ contentIntent จากเครื่องจริง

## ตัวอย่าง 002 — มีทิป (ผู้ใช้ยืนยัน)

- หัวข้อ: `[ขนส่งสินค้า] บางคูรัด > หัวหมาก`
- ข้อความ: `ขนส่งทันที ฿276.00 + ฿10.00 รับงานขนส่ง!`
- ราคางาน 276.00 บาท, ทิป 10.00 บาท, รวม 286.00 บาท
- หากค่าธรรมเนียม 20%: ฐานสุทธิ 220.80 บาท; ฐานสุทธิรวมทิป 230.80 บาท
- ตัวอย่างที่สอง: `[ขนส่งสินค้า] คลองพระอุดม > สา...` (ปลายทางถูกตัดในภาพ ไม่ทราบชื่อเต็ม), ข้อความ `ขนส่งทันที ฿129.00 + ฿18.00 รับงานขนส่ง!` รวม 147.00 บาท
- รุ่น 0.1.0 ปฏิเสธสองจำนวน จึงไม่เปิดงานรูปแบบนี้ รุ่น 0.1.1 รองรับสองจำนวนคั่นด้วย `+`
- ภาพไม่ยืนยัน extras หรือสาเหตุที่งานไม่มีทิปไม่ทำงาน ต้องขอผลตรวจจากมือถือ
