# Full Lock v0.1.25

- เปิดหน้าขอสิทธิ์ที่ยังขาดให้อัตโนมัติเมื่อเปิดแอปครั้งแรก
- กลับเข้าแอปแล้วไปข้อถัดไป ข้ามสิทธิ์ที่อนุญาตแล้ว และไม่ถามวนเมื่อปฏิเสธในรอบนั้น
- ผู้ใช้ยังกดอนุญาตเองใน Android เลือกทำภายหลังได้ และกลับมาจัดการจากเมนู
- ไม่เริ่มเปิดงานอัตโนมัติระหว่างตั้งค่าสิทธิ์

ตรวจบิลด์และ lint ผ่าน ชุดทดสอบบน Android 35: Overlay 102, Filter 20, History 8 และ UI 61 ข้อผ่าน ตรวจขั้นตอนเปิด Usage access → ย้อนกลับ → Battery settings → ย้อนกลับ Full Lock โดยไม่วนถามซ้ำแล้ว ยังไม่ได้ทดสอบโทรศัพท์แต่ละยี่ห้อ
