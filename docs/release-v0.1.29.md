# Full Lock v0.1.29

- คืนการเปิดงานผ่านแจ้งเตือนขณะใช้โหมดอ่านงานบนหน้า Driver เมื่องานผ่านเงื่อนไขที่อ่านจากแจ้งเตือนได้
- เพิ่มการอ่านและวาดข้อมูลในหน้ารายละเอียดงาน ทั้งงานที่เปิดเองและเปิดผ่านแจ้งเตือน ข้อมูลที่อ่านได้แสดงตามสวิตช์วาดทับ ส่วนเครื่องหมายตรงเงื่อนไขจะแสดงเมื่ออ่านครบและผ่านเงื่อนไขทั้งหมด
- งานที่ Full Lock เปิดจากแจ้งเตือนโดยอัตโนมัติ หากอ่านรายละเอียดครบแล้วไม่ผ่านเงื่อนไข จะรอ 3 วินาทีแล้วย้อนกลับ ไม่ย้อนกลับอัตโนมัติจากงานที่ผู้ใช้เปิดเอง
- เพิ่มตัวกรองระยะห่างจากผู้ใช้ไปจุดรับ แยกจากระยะทางจุดรับไปจุดส่ง รองรับหน่วยเมตรและกิโลเมตร และรอข้อมูลก่อนตัดสินใจเมื่อเปิดตัวกรองนี้
- ปรับการวางข้อมูลบนหัวหน้ารายละเอียด ให้ติดตามตำแหน่งหัวเรื่องและย่อเมื่อพื้นที่ลดลง พร้อมแก้พื้นที่วาดของงานล่วงหน้า งานผู้โดยสาร ป้ายลดค่าคอมมิชชัน และการ์ดภาพพื้นหลัง
- เพิ่มป้ายตรงเงื่อนไขกระพริบเบา ๆ และกรอบด้านนอกแถบรับงาน เลือกกรอบไล่สี RGB สีของป้าย และจังหวะกระพริบ 0.5–5 วินาทีต่อรอบได้ในหน้าธีม แผงตัวเลขยังใช้พื้นขาว/เขียวอ่อนและตัวอักษรดำ
- เพิ่มข้อมูลต้นทางแบบทดลองสำหรับกลุ่มทดสอบ เปิดจากตั้งค่าการวาดทับผ่านคำเตือนและรหัสที่ผู้พัฒนาให้ แสดงตัวเลขพิกัดย่อข้างต้นทาง เมื่ออ่านและจับคู่งานได้ แตะเพื่อคัดลอกพิกัดเต็ม โดยไม่เก็บพิกัดเพิ่มลงประวัติหรือไฟล์โปรไฟล์

## อัปเดตและขอบเขต

ส่วนเสริมภายในเป็นรุ่น 0.0.31 เมื่ออัปเดตแล้วให้เปิด Full Lock เพื่อให้แอปตรวจส่วนเสริม หากข้อมูลไม่ขึ้น ให้ปิด Driver ให้สนิทแล้วเปิดใหม่ หรือรีสตาร์ตเครื่องตามความจำเป็น สิทธิ์รูทและ LSPosed ยังจำเป็นสำหรับการอ่านงานบนหน้า Driver

เครื่องทั่วไปยังอ่านและเปิดงานจากแจ้งเตือนตามเดิม ผู้ใช้ยังต้องปัดรับงานเอง รุ่นนี้ไม่มีการปัดรับงานอัตโนมัติ กรอบรอบแถบรับงานเป็นเพียงการวาดภาพ

ผ่านชุดทดสอบตัวกรอง/การคำนวณ/โปรไฟล์/พิกัด/การจัดวาง/ไฟล์เว็บ 294 ข้อ และชุดทดสอบการเชื่อมต่อ/การตรวจผู้ส่ง/หน้ารายละเอียดบนเครื่อง 32 ข้อ ตรวจลายเซ็นทางการของ APK และส่วนเสริมที่ฝังแล้ว ก่อนหน้านี้ทดสอบหน้ารหัสกลุ่มทดสอบและกรอบวาดบนเครื่องแยกด้วย

ตรวจพบแท็กพิกัดบนหน้ารายการจริงแล้ว บางกรณีของหน้ารายละเอียด การเลื่อน Header และการกลับอัตโนมัติยังอาศัยการทดสอบตรรกะร่วมกับการทดสอบหน้าจอบางส่วน ไม่รับรองการแสดงครบทุกงานหรือทุก ROM หากอ่านข้อมูลที่ยืนยันไม่ได้ แอปจะไม่ใช้ข้อมูลของงานอื่นแทน

เผยแพร่ APK เต็มรวมส่วนเสริมภายใน พร้อมไฟล์ดาวน์โหลดเว็บและบันทึกรุ่นเท่านั้น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo เป็นรุ่นก่อนหน้า ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่เผยแพร่ Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนาม

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
