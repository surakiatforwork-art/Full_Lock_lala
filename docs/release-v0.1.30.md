# Full Lock v0.1.30

- ย่อแผงข้อมูลหน้ารายละเอียดเฉพาะงานรับ–ส่งผู้โดยสาร ให้สูงพอดีกับชื่อช่วงเวลาและระยะจากคุณ งานขนส่งสินค้ายังคงแผงขนาดเดิม
- ปรับราคาเฉลี่ยที่วาดทับให้ใช้วิธีคิดราคาและค่าธรรมเนียมตามโปรไฟล์ พร้อมตัวเลือกรวมระยะไปจุดรับ งานล่วงหน้าแสดงราคาเฉลี่ยจากระยะทางงานเท่านั้น
- ปรับรายได้สุทธิเป็นบรรทัดเดียว ตัวเลขชิดขวา และปรับชั้นวาดพิกัดให้เลื่อนตามต้นทางใต้ Header
- แก้การจับคู่พิกัดหน้ารายละเอียดเมื่อราคาที่แสดงต่างจากโมเดลงาน และทดสอบกรณีหลายจุดส่ง ไม่แสดงพิกัดที่ยืนยันไม่ได้หรือถูกปิดบัง
- เพิ่มตัวเลือกไม่มีบริการเสริม จัดตัวเลือกเป็นสองคอลัมน์ ย้ายการอ่านงานบนหน้า Driver และการตั้งค่ากดซ้ำไปเมนูด้านข้าง เพิ่มไม่กดงานซ้ำ
- ปรับสวิตช์ให้มองชัดและมีเงา ปรับแถบปัดเริ่ม และลดภาระการอ่าน/วาดข้อมูล โดยคงการอ่านการ์ดที่มองเห็นแบบเดิม

## การอัปเดต

เปิด Full Lock หลังติดตั้ง เพื่อให้แอปตรวจและอัปเดตส่วนเสริมภายใน จากนั้นปิด Driver ให้สนิทแล้วเปิดใหม่ หากส่วนเสริมยังไม่ทำงาน อาจต้องรีสตาร์ตเครื่อง โหมดอ่านงานบนหน้า Driver ยังต้องใช้รูทและ LSPosed

ผู้ใช้ยังปัดรับงานเอง รุ่นนี้ไม่มีการปัดรับงานอัตโนมัติ ไม่เพิ่มบริการคำนวณเส้นทางภายนอก

## การตรวจสอบ

ผ่านชุดทดสอบการจัดวาง พิกัด สูตรราคา ตัวกรอง การกดซ้ำ ลำดับความสำคัญ และโปรไฟล์ 277 ข้อ รวมชุดทดสอบไฟล์เว็บ 18 ข้อ ตรวจลายเซ็นของแอปและส่วนเสริม พร้อมตรวจว่า APK ฝังส่วนเสริมตรงกับตัวที่สร้างแล้ว ชุดทดสอบการวาดบนเครื่องผ่าน 30 ข้อก่อนการย่อแผงผู้โดยสารครั้งนี้

การทดสอบบางส่วนใช้ข้อมูลจำลอง ยังไม่ยืนยันการแสดงครบทุกงาน/ทุก ROM โดยเฉพาะพิกัดและการเลื่อนหน้ารายละเอียด หากยืนยันข้อมูลไม่ได้ แอปจะไม่ใช้พิกัดของงานอื่นแทน

เผยแพร่ APK เต็มรวมส่วนเสริมภายใน พร้อมไฟล์ดาวน์โหลดเว็บและบันทึกรุ่นเท่านั้น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo เป็นรุ่นก่อนหน้า ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่เผยแพร่ Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนาม

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
