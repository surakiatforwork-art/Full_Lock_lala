# Full Lock v0.1.21 — งานผู้โดยสารและตัวเลือกหลายประเภท

- ลดความสูง header หน้าตัวกรอง โดยลดช่องว่าง ขนาดชื่อหน้า และตัดบรรทัดคำอธิบายออก คงช่องโปรไฟล์และปุ่มจัดการ
- เพิ่มตัวเลือกบริการ “ขนส่งสินค้า” และ “รับ-ส่งผู้โดยสาร” เลือกได้พร้อมกัน และเลือกเวลา “ขนส่งทันที”/“งานล่วงหน้า” ได้พร้อมกัน ต้องเหลืออย่างน้อยหนึ่งตัวเลือกในแต่ละกลุ่ม
- โปรไฟล์เดิมยังใช้เงื่อนไขเวลาเดิมและเลือกขนส่งสินค้าเป็นค่าเริ่มต้น ไม่เพิ่มงานผู้โดยสารเอง ผู้ใช้เปิดรับได้จากหน้าตัวกรอง
- แผงงานปุ่มลอยแสดงประเภทบริการคู่กับเวลา เพื่อแยกงานผู้โดยสารออกจากขนส่งสินค้า
- เว็บสร้างโปรไฟล์มีตัวเลือกเดียวกับแอป ข้อมูลบริการบันทึกในโปรไฟล์ ทำสำเนา สลับ นำเข้า และส่งออกได้
- ส่งออก FLP v2 โดยเพิ่ม serviceMask ที่ field 27 ไม่เปลี่ยน field เก่า แอปรุ่นใหม่นำเข้า v1 ได้ ส่วนรุ่นเก่าจะขอให้อัปเดตก่อนอ่าน v2 เพื่อไม่ตีความผิด

## การตรวจสอบ

- ParserChecks 36, ProfileFileChecks 39 และ FlpWebChecks 16 ผ่าน รวมไฟล์เก่า ค่าเลือกหลายบริการ และตรวจข้อมูลเสีย
- เว็บสร้างไฟล์ให้ Java ของ Android อ่านกลับได้ครบทั้งบริการ เส้นทางไทยและเส้นทางยกเว้น
- เครื่องจำลอง: OverlayChecks 99, FilterChecks 12, HistoryChecks 8, UiChecks 62, ProfileChecks 37 และ ProfileUiChecks 56 ผ่านก่อนเพิ่มหมายเลขรุ่น
- ตรวจ header จากภาพจริงบนเครื่องจำลอง ฟอร์มเว็บขนาดมือถือ 390px เลือกทั้งสองบริการได้และสร้างลิงก์ไฟล์ได้ ไม่มีหน้าล้นแนวนอน ระบบอัตโนมัติของเบราว์เซอร์ไม่คืนไฟล์ดาวน์โหลด จึงตรวจข้ามเว็บ/Java แยกด้วย reference encoder
- Build release พร้อม R8 และ lintRelease ผ่าน ใช้กุญแจลงนามเดิม อัปเดตทับได้ ยังไม่ได้ทดสอบบนโทรศัพท์จริงของผู้ใช้
