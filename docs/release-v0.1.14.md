# Full Lock v0.1.14 — จัดการโปรไฟล์

- dropdown บนหน้าตัวกรองแสดงเฉพาะรายชื่อโปรไฟล์
- แตะชื่อโปรไฟล์บน header เพื่อเปลี่ยนเป็นช่องแก้ชื่อ บันทึกด้วย ✓ หรือปุ่มเสร็จบนแป้นพิมพ์
- ปุ่ม “จัดการ” ด้านขวาเปิดหน้าจัดการโปรไฟล์แยก เพิ่มโปรไฟล์โดยตั้งชื่อก่อน นำเข้า ทำสำเนา และส่งออก .flp ได้
- ลบโปรไฟล์แบบเลือกหลายรายการ แล้วกดยืนยันรายการที่เลือก ก่อนพบคำเตือน “โปรไฟล์ที่ลบจะนำกลับมาไม่ได้แล้ว” พร้อมปุ่มยืนยันลบ/ไม่ลบ
- ป้องกันการลบโปรไฟล์สุดท้าย หากลบโปรไฟล์ที่ใช้อยู่ แอปเลือกโปรไฟล์ที่เหลือแทนและใช้เงื่อนไขใหม่กับงานถัดไป
- ยกเลิกการลบแล้วไม่มีข้อมูลเปลี่ยน การลบหลายรายการบันทึกพร้อมกันเพื่อไม่ให้เหลือสถานะครึ่งทาง

รองรับ Android 8 ขึ้นไป ลงนามด้วยกุญแจเดิมเพื่ออัปเดตทับรุ่นใช้งานจริงได้ ไฟล์ .flp ใช้รูปแบบเดิม

## การตรวจสอบ

- Build release พร้อม R8 และ lintRelease ผ่าน
- ProfileChecks 36 และ ProfileUiChecks 56 ผ่านบนเครื่องจำลอง รวมการเพิ่ม เปลี่ยนชื่อ สลับระหว่างทำงาน นำเข้าชื่อซ้ำ ส่งออก ลบหลายรายการ ยกเลิก และป้องกันลบรายการสุดท้าย
- OverlayChecks 76, FilterChecks 7, HistoryChecks 8 และ UiChecks 54 ผ่าน
- ตรวจภาพช่องแก้ชื่อ dropdown หน้าจัดการ และคำเตือนก่อนลบแล้ว
- ยังไม่ได้ทดสอบบนโทรศัพท์จริงของผู้ใช้
