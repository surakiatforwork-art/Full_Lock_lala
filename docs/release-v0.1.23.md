# Full Lock v0.1.23 — บังคับอัปเดตเมื่อพบรุ่นใหม่

- ตรวจ version.json จากเว็บไซต์เมื่อเข้าแอป โดยเว้นตรวจเครือข่ายอย่างน้อย 15 นาที และตรวจทุก 6 ชั่วโมงขณะตัวอ่านแจ้งเตือนเชื่อมต่อ
- เมื่อยืนยันว่ามีรุ่นใหม่ แสดง popup “กรุณาอัปเดต Full Lock” พร้อมปุ่มเดียว “ไปดาวน์โหลด” เปิดหน้าเว็บไซต์ ปิดด้วย Back หรือแตะนอกไม่ได้ กดดาวน์โหลดแล้วกลับมายังไม่ปลดล็อก
- จำข้อกำหนดอัปเดตไว้บนเครื่อง เปิดแอปซ้ำหรือออฟไลน์ภายหลังยังต้องอัปเดตจนติดตั้งรุ่นเดียวกันหรือใหม่กว่า หากยังไม่เคยพบรุ่นใหม่และตรวจเครือข่ายไม่สำเร็จ จะไม่ล็อกแอป
- หยุดเปิดงานอัตโนมัติ ซ่อนปุ่มลอย และปิดการประมวลผลงาน/เปิดจากประวัติในรุ่นเก่าที่ถูกบล็อก ยกเลิกแจ้งเตือนเปิดงานเก่า หากตรวจพบขณะอยู่เบื้องหลังจะแจ้งเตือน และแสดง popup เมื่อเข้า Full Lock
- เชื่อมต่อ HTTPS เฉพาะข้อมูลรุ่นสาธารณะ ไม่ส่งข้อมูลงานขึ้นเว็บไซต์ จำกัดเวลา/ขนาดข้อมูล ตรวจเลขรุ่น SHA256 และขนาด APK ก่อนรับข้อมูล ไม่ติดตั้งอัตโนมัติ

ฟีเจอร์เริ่มใน 0.1.23 เท่านั้น รุ่น 0.1.22 และก่อนหน้าไม่มีตัวตรวจ ต้องติดตั้งรุ่นนี้ก่อนจึงรับกติกาบังคับอัปเดตในอนาคตได้

## การตรวจสอบ

- UpdateChecks 25 ข้อผ่านบนเครื่องจำลอง รวมเปรียบเทียบรุ่น ข้อมูลผิด Popup ปุ่มเดียว Back ไม่ปิด เปิดเว็บ แล้วยังล็อก และเข้าแอปใหม่จากข้อมูลที่จำไว้
- OverlayChecks 102, FilterChecks 12, HistoryChecks 8 และ UiChecks 61 ผ่าน รวมไม่ประมวลผลงานเมื่อถูกบังคับอัปเดต
- Build release พร้อม R8 และ lintRelease ผ่าน ลงนามด้วยกุญแจเดิม อัปเดตทับได้
- ยังไม่ได้ทดสอบบนโทรศัพท์จริงของผู้ใช้
