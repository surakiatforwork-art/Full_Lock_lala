# Full Lock v0.1.28

- เปลี่ยนช่องทางเชื่อมต่อของโหมดอ่านงานบนหน้า Driver (รูท) เพื่อรองรับการซ่อนรายชื่อ Full Lock ด้วย HMA ตามผลทดสอบบนเครื่องที่ใช้พัฒนา
- ข้อมูลวาดทับและเครื่องหมายตรงเงื่อนไขยังแสดงได้ขณะการตรวจแพ็กเกจจาก Driver ไม่พบ Full Lock
- ปิดโหมดรูทแล้วหยุดวาดทับ เมื่อเปิดกลับหรือเปิด Driver ใหม่สามารถเชื่อมต่อกลับได้
- เพิ่มการตรวจผู้เชื่อมต่อ รูปแบบข้อความและเวลารอ เมื่อขาดช่องทางควบคุมไม่สั่งเปิดงานจากข้อมูลค้าง
- เมื่อติดตั้งรุ่นนี้แล้วเปิด Full Lock หากเคยเปิดโหมดรูทและมี Probe รุ่นเก่า แอปจะตรวจและเตรียมส่วนเสริมรุ่นใหม่ให้ ต้องยังได้รับสิทธิ์รูท หากข้อมูลยังไม่ขึ้นหลังอัปเดตส่วนเสริม ให้ปิด Driver ให้สนิทแล้วเปิดใหม่ หรือเลือกรีสตาร์ตเครื่องภายหลัง ไม่มีการบังคับรีสตาร์ต
- เครื่องทั่วไปยังอ่านแจ้งเตือนได้ตามเดิม ผู้ใช้ยังปัดรับงานเอง

## ผลตรวจและขอบเขต

ตรวจบนเครื่องพัฒนาแล้ว: แพ็กเกจ Full Lock ไม่ปรากฏต่อการตรวจจาก Driver แต่ช่องทางใหม่รับข้อมูลสดและวาดทับได้ ทดสอบปิด/เปิดโหมดรูท เปิด Driver ใหม่ และพักโปรเซส Full Lock ชั่วคราวแล้วกลับมาเชื่อมต่อได้ ไม่ได้กดรับงานจริง
ทดสอบอัปเดตจาก Probe รุ่นทดลองเก่าเป็น 0.0.27 อัตโนมัติผ่าน และทดสอบ protocol/การปฏิเสธผู้เชื่อมต่อปลอม/การตรวจรุ่นส่วนเสริม 18 ข้อผ่าน
บิลด์ release พร้อม R8 และตรวจลายเซ็นทางการ app/Probe พร้อมความตรงกันของโมดูลที่ฝังและรูปแบบข้อมูลลับใน APK ผ่าน

ไม่คัดลอกโค้ด HMA ไม่แก้กฎซ่อนของผู้ใช้ ไม่ลดการป้องกัน SELinux และไม่มีเซิร์ฟเวอร์ภายนอกสำหรับรับข้อมูลงาน ยังต้องทดสอบ ROM และโมดูลซ่อนรุ่นอื่นเพิ่มเติม ผลนี้ไม่ใช่การรับประกันว่าจะตรวจไม่พบทุกวิธีหรือใช้ได้กับทุกเครื่อง

เผยแพร่ APK เต็มรวมโมดูลภายใน แต่ไม่เผยแพร่ซอร์สใหม่หรือซอร์สรูท/Xposed ซอร์ส Android สาธารณะใน repo ยังเป็นรุ่นก่อนหน้า ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่เผยแพร่ Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนาม
Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove ผู้ใช้ควรพิจารณาเงื่อนไขของบริการที่ใช้งานร่วมกัน
