# Full Lock PHANToM — เว็บไซต์ดาวน์โหลดและไฟล์โปรไฟล์

ข้อตกลงวันที่ 23 ตุลาคม 2026 สำหรับทำเว็บไซต์ต่อจากแอป v0.1.12 เอกสารนี้เป็นข้อกำหนดร่วมกับแอป ไม่ใช่เว็บไซต์ที่เผยแพร่แล้ว

## เป้าหมายเว็บไซต์

1. หน้าแนะนำ Full Lock พร้อมไอคอน ชื่อผู้พัฒนา PHANToM และปุ่มดาวน์โหลด APK รุ่นใช้งานจริงล่าสุด
2. อธิบายการอนุญาตสิทธิ์ การอ่านแจ้งเตือน และการปัดรับงานเองใน Lalamove Driver
3. ตัวสร้างโปรไฟล์: ตั้งชื่อ เลือกต้นทาง/ปลายทางหลายรายการ และเส้นทางที่ไม่ต้องการ พร้อมเลือกช่วงราคา วิธีคิดราคา ค่าธรรมเนียม ประเภทงาน งานเหมา สีธีม และสีข้อความ
4. แสดงพื้นที่ที่เลือกเป็นรายการ/ชิป เพิ่มและลบได้ ก่อนบันทึกเป็น `.flp` ให้ดาวน์โหลดจากเบราว์เซอร์ แล้วเปิด Full Lock → โปรไฟล์ → นำเข้า .flp
5. สร้างไฟล์ในเบราว์เซอร์ได้ ไม่ต้องมีบัญชี รหัสผ่าน เซิร์ฟเวอร์สร้างไฟล์ หรือส่งรายชื่อพื้นที่ให้เซิร์ฟเวอร์ ไม่ฝังกุญแจลับในเว็บไซต์
6. คำอธิบายกรณีชื่อพื้นที่ซ้อน เช่น ต้องการ “คลองสาม” และไม่ต้องการ “คลองสามประเวศ” การยกเว้นมีสิทธิ์ก่อนเส้นทางที่ต้องการ
7. หากจะมีฐานข้อมูลพื้นที่/ค้นหา/เลือกจังหวัดและเขตภายหลัง ต้องกำหนดแหล่งข้อมูลและรูปแบบชื่อที่จะตรงกับแจ้งเตือนจริงก่อน ไม่อนุมานว่าชื่อเขตเพียงอย่างเดียวจะตรงกับทุกงาน

ตัวสร้างบนเว็บต้องตั้ง `originOn`/`destOn`/`excludeOriginOn`/`excludeDestOn` ตามตัวเลือกที่ผู้ใช้เปิด ไม่ส่งแต่รายชื่อโดยลืมสวิตช์เปิดใช้ รายชื่อในไฟล์เป็นข้อมูลล้วน แสดงชื่อ/พื้นที่ด้วย textContent ไม่แทรกเป็น HTML

ดาวน์โหลด APK ใช้ GitHub Release และ SHA256SUMS ของ release นั้น ณ วันที่เขียน URL รุ่นล่าสุดเป็น `https://github.com/surakiatforwork-art/Full_Lock_lala/releases/latest` ควรดึง release ปกติที่เผยแพร่แล้ว หลีกเลี่ยง debug/draft/prerelease อย่าฝังกุญแจลงนามหรือ mapping ในเว็บหรือไฟล์ดาวน์โหลด

## ระบบโปรไฟล์ที่ตกลง

- Header หน้าตัวกรอง: `โปรไฟล์: ชื่อที่เลือก ▾`
- ย้ายค่าปัจจุบันมาเป็น “โปรไฟล์เริ่มต้น” ครั้งแรก ชื่อนี้แก้ได้ ไม่บังคับผูกกับชื่อเดิม
- ต้องมีโปรไฟล์ใช้งานหนึ่งรายการเสมอ รองรับเพิ่ม เปลี่ยนชื่อ ทำสำเนา ลบ นำเข้า และส่งออก สูงสุด 50 รายการ
- การแก้ตัวกรอง/สีบันทึกลงโปรไฟล์ที่เลือกทันที
- สลับขณะเปิดงานอัตโนมัติต้องยืนยัน เงื่อนไขใหม่ใช้กับงานที่เข้าหลังสลับ ไม่ย้อนกลับไปเปิดประวัติเอง
- ลบโปรไฟล์ที่ใช้อยู่แล้วเลือกอีกโปรไฟล์ให้อัตโนมัติ ไม่ให้ลบรายการสุดท้าย
- ค่าของโปรไฟล์: ราคา วิธีคิดราคา ค่าธรรมเนียม ต้นทาง/ปลายทางที่ต้องการและไม่ต้องการ ประเภทงาน งานเหมา สีธีม สีข้อความ
- ค่ากลางของแอป: สิทธิ์ เปิด–ปิดปุ่มลอย ความเร็วแผง ประวัติ สถานะเริ่ม–หยุด ตำแหน่งปุ่มลอย
- ไฟล์ไม่ส่งออก UUID ของโปรไฟล์ ไม่ผูกกับเครื่องหรือรุ่นแอป และไม่ส่งออกประวัติหรือคำสั่งเปิดแจ้งเตือน

### ชื่อซ้ำเมื่อนำเข้า

ตัดช่องว่างหัวท้ายและ normalize Unicode เป็น NFC เปรียบเทียบชื่อโดยไม่แยกตัวพิมพ์ภาษาอังกฤษ เมื่อพบชื่อซ้ำให้แสดง:

> โปรไฟล์นี้มีอยู่แล้ว ต้องการติดตั้งทับหรือไม่?
> “ชื่อโปรไฟล์”

ปุ่ม: **ติดตั้งทับ** / **ยกเลิก**

ยกเลิกแล้วไม่เปลี่ยนข้อมูลใด ๆ ติดตั้งทับแล้วแทนค่าทั้งชุดด้วยข้อมูลจากไฟล์ โดยคง UUID เดิม ไม่สร้างชื่อซ้ำ และเลือกโปรไฟล์นั้นใช้งาน หากกำลังเปิดอัตโนมัติ ต้องแจ้งในกล่องยืนยันด้วยว่าเงื่อนไขใหม่ใช้กับงานที่เข้าหลังติดตั้ง

ชื่อใหม่: แสดงชื่อและสรุปช่วงราคา ให้ยืนยัน **ติดตั้ง** / **ยกเลิก** จากนั้นเลือกโปรไฟล์ที่ติดตั้ง ชื่อซ้ำจากการเพิ่ม/เปลี่ยนชื่อด้วยมือให้แก้ชื่อ ไม่ติดตั้งทับโดยอัตโนมัติ

## `.flp` = Full Lock PHANToM

ไบนารีข้อมูลล้วน บีบอัด zlib ไม่เข้ารหัส ไม่ต้องมีรหัสผ่าน ตรวจความเสียหายด้วย CRC-32 และตรวจค่าทั้งหมดก่อนเขียนลงแอป ไม่มีการรันสคริปต์ ไฟล์นี้ไม่ได้รับประกันว่าเฉพาะแอปนี้เท่านั้นที่อ่านได้ และ CRC ไม่ใช่ลายเซ็นยืนยันผู้สร้าง

ตัวเลข format version ภายในคือรุ่นโครงสร้างไฟล์ ไม่ใช่รุ่นแอป ไม่ขัดขวางการแชร์ข้ามเครื่อง ใช้เวอร์ชัน `1` สำหรับรูปแบบนี้

### โครงไฟล์ v1

จำนวนเต็มทั้งหมดใช้ **big-endian** ไฟล์หนึ่งเก็บหนึ่งโปรไฟล์

| Offset | Bytes | ความหมาย |
|---|---:|---|
| 0 | 8 | ASCII `FLP-PHTM` |
| 8 | 1 | รูปแบบ `1` |
| 9 | 4 | ความยาว payload ที่บีบอัด (uint32) |
| 13 | 4 | ความยาวข้อมูลก่อนบีบอัด (uint32) |
| 17 | 4 | CRC-32/IEEE ของข้อมูลก่อนบีบอัด (uint32) |
| 21 | ตามขนาด | zlib payload (RFC1950; ไม่ใช่ gzip/deflate-raw/ZIP) |

ข้อมูลก่อนบีบอัดขึ้นต้นด้วยจำนวน record (uint16) แล้วตามด้วยแต่ละ record:

`field ID (uint8) | type (uint8) | byte length (uint32) | value bytes`

Type 1 = UTF-8 แบบมาตรฐาน, type 2 = boolean หนึ่งไบต์ 0/1, type 3 = int32 สี่ไบต์แบบ signed สตริงไม่ใช่ Java modified UTF-8

| ID | Key | Type | ค่าเริ่มต้น |
|---:|---|---|---|
| 1 | name | string | จำเป็นต้องมี ชื่อไม่ว่าง สูงสุด 60 code points |
| 10 | price | bool | true |
| 11 | min | string | `100` |
| 12 | max | string | `2000` |
| 13 | formula | int32 | 0 |
| 14 | fee | int32 | 20 |
| 15 | originOn | bool | false |
| 16 | origins | string | ว่าง |
| 17 | destOn | bool | false |
| 18 | destinations | string | ว่าง |
| 19 | excludeOriginOn | bool | false |
| 20 | excludedOrigins | string | ว่าง |
| 21 | excludeDestOn | bool | false |
| 22 | excludedDestinations | string | ว่าง |
| 23 | type | int32 | 0 |
| 24 | bulk | bool | false |
| 25 | themeColor | int32 | ARGB `0xFFE94A19` (signed -1488359) |
| 26 | invertText | bool | false |

Formula: 0 ราคางาน, 1 ราคางาน+ทิป, 2 หักค่าธรรมเนียม, 3 หักค่าธรรมเนียม+ทิป Fee 0–100, type 0 ทั้งหมด / 1 ขนส่งทันที / 2 งานล่วงหน้า สีต้องเป็น ARGB ทึบ (alpha 255) ราคาเป็นเลขฐานสิบไม่ติดลบ สูงสุด 10 หลักหน้าจุดและ 2 หลักหลังจุด และ min ≤ max รายชื่อพื้นที่คั่นด้วยจุลภาค

Field ที่ไม่ส่งมาจะใช้ค่าเริ่มต้น ยกเว้น name จำเป็นต้องมี ห้าม field ซ้ำ/ชนิดผิด/field ที่ไม่รู้จัก ไม่ยอมรับเวอร์ชันอนาคตแบบเดาค่าเอง ทุกการแทนที่ใช้ข้อมูลที่ผ่านการตรวจแล้วทั้งชุด ไม่ผสมกับค่าที่หายไปจากโปรไฟล์เดิม

จำกัดไฟล์รวม 1 MiB ข้อมูลคลายบีบอัดไม่เกิน 256 KiB แต่ละ string value ไม่เกิน 16 KiB ชื่อห้ามอักขระควบคุม ตรวจ CRC ความยาว UTF-8 เงื่อนไข และข้อมูลเกินท้ายไฟล์/ท้าย zlib ก่อนติดตั้ง ป้องกันการคลายข้อมูลเกินขนาด

## โค้ดอ้างอิงและการทดสอบข้ามแพลตฟอร์ม

- แอป: `app/src/main/java/com/fulllock/app/ProfileFile.java`
- ตัวสร้างสำหรับ browser/Node: `tools/flp-web-codec.mjs` → `await encodeProfile(name, settings)` คืน Uint8Array
- เว็บสร้าง `Blob([bytes], {type:'application/octet-stream'})` แล้วใช้ object URL กับ `<a download="ชื่อ.flp">` เมื่อเสร็จ revoke URL
- ค่า ARGB ใน JavaScript ให้ใช้ signed int32 เช่น `0xff2563eb | 0`
- อ้างอิงการบีบอัด: [WHATWG CompressionStream](https://compression.spec.whatwg.org/) ใช้ `new CompressionStream('deflate')` (มี zlib wrapper)
- แอปใช้ [Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files) เลือก/บันทึกไฟล์ ไม่ขอสิทธิ์เข้าถึงพื้นที่จัดเก็บทั้งหมด
- Pure-Java tests: `tests/ProfileFileChecks.java` ตรวจ round trip และไฟล์เสีย/ผิดโครงสร้าง
- Node tests: `tests/flp-web-checks.mjs` อ่านไฟล์ Java และสร้างไฟล์เว็บให้ Java ตรวจกลับ
- Fixtures สร้างไว้ใน ignored `app/build/profile-fixtures/` ตัวอย่างชื่อ/เส้นทางไทยประมาณ 190 ไบต์ ขนาดจริงขึ้นกับจำนวนพื้นที่

## งานเว็บไซต์ที่ยังไม่เริ่ม

เลือกหน้าตาเว็บ โดเมน/โฮสติ้ง ฐานข้อมูลพื้นที่จริง แหล่งรายชื่อจังหวัด/เขต/แขวง UX ตัวเลือกหลายพื้นที่ และการดึง Release ล่าสุด เอกสารและ reference encoder นี้พร้อมให้เริ่มงานรอบเว็บไซต์ โดยยังไม่มีการสร้างหรือเผยแพร่เว็บไซต์ในรอบแอปนี้
