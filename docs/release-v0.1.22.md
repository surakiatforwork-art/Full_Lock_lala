# Full Lock v0.1.22 — เลือกบริการเดียว

- ขนส่งสินค้า/รับ-ส่งผู้โดยสารเลือกได้อย่างใดอย่างหนึ่งด้วยปุ่มวงกลม ทั้งแอปและเว็บ
- เวลาขนส่งทันที/งานล่วงหน้ายังเลือกพร้อมกันได้
- โปรไฟล์ที่เลือกบริการเดียวอยู่แล้วคงเดิม โปรไฟล์ 0.1.21 ที่เลือกทั้งสองจะปรับเป็นขนส่งสินค้า รวมถึงการนำเข้า .flp เดิม ผู้ใช้เลือกผู้โดยสารใหม่ได้
- ส่งออก .flp v2 ตามเดิม แต่มีบริการเดียว เว็บปฏิเสธการสร้างไฟล์ที่เลือกสองบริการ

ตรวจไฟล์ข้าม Java/เว็บผ่าน ProfileFileChecks 40 และ FlpWebChecks 17 ข้อ Build release และ lintRelease ผ่าน ลงนามด้วยกุญแจเดิม
