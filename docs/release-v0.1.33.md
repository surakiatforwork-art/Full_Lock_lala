# Full Lock v0.1.33

- เพิ่มการเคลื่อนไหวขณะเปลี่ยนสีสวิตช์ กาง–หุบส่วนตั้งค่า เปิด–ปิดเมนูด้านข้าง เลือกโปรไฟล์ และเปลี่ยนหน้า
- ความเร็วอิงแอนิเมชันของ Android เมื่อปิดแอนิเมชันในระบบ จะแสดงสถานะทันที
- คงตำแหน่งเลื่อนและสถานะส่วนตั้งค่าเมื่อแก้ค่า ไม่เล่นแอนิเมชันทั้งหน้าซ้ำทุกครั้ง
- ไม่เปลี่ยนระยะเวลาปัดรับงานหรือเวลาหน่วงคำสั่งตามความเร็วแอนิเมชัน

## การตรวจสอบ

ผ่าน 64 จุดตรวจในแอป QA แยกบนเครื่องจำลอง: การเคลื่อนไหว 42 จุดที่ค่าระบบ 0×, 1× และ 2× และการคงตำแหน่งเลื่อน/เมนู/ธีม/การสร้างหน้าจอใหม่ 22 จุด สร้าง release ผ่าน ตรวจลายเซ็นทางการและส่วนเสริมที่ฝังใน APK พร้อมยืนยันว่าไม่มีชุดทดสอบอุปกรณ์ติดไป

ไม่ได้ทดสอบการปัดรับงานจริง ฟีเจอร์ปัดรับงานอัตโนมัติยังมีค่าเริ่มต้นปิดและต้องยืนยันความเสี่ยงก่อนเปิด

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริมภายใน ไฟล์ดาวน์โหลดเว็บ metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
