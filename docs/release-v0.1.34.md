# Full Lock v0.1.34

- เปิดภาพนิ้วจำลองพร้อมปัดรับงานอัตโนมัติได้ ใช้ตำแหน่งและระยะเวลาปัดชุดเดียวกัน ภาพนิ้วติดตามเหตุการณ์สัมผัสที่เกิดขึ้นจริง
- เมื่อปิดปัดรับงานอัตโนมัติ ยังดูภาพจำลองได้ตามเดิม
- เอาข้อความ “จำลองเท่านั้น · ไม่รับงาน” ออกจากภาพวาดทับ และปรับคำอธิบายตั้งค่า

## การตรวจสอบ

สร้าง release ผ่าน ตรวจลายเซ็นทางการ ผ่าน 20 จุดตรวจการอนุญาต/อายุคำสั่ง/ป้องกันซ้ำ/ตำแหน่งปัด, 17 จุดตรวจเวลาภาพจำลอง และ 15 จุดตรวจการติดตามสัมผัสโดยไม่ส่ง input ติดตั้งแอปและส่วนเสริมบนเครื่องทดสอบแล้ว โดยปิดปัดรับงานอัตโนมัติไว้ ไม่ได้ทดลองรับงานจริง

ผู้ที่เคยเปิดปัดรับงานอัตโนมัติและภาพจำลองพร้อมกัน ต้องทราบว่ารุ่นนี้จะส่งคำสั่งปัดจริงเมื่อเริ่มทำงานและงานตรงเงื่อนไข ภาพจำลองไม่ยับยั้งคำสั่งปัดอีกต่อไป โปรดปิดปัดรับงานอัตโนมัติหากต้องการดูภาพจำลองอย่างเดียว

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริมภายใน ไฟล์ดาวน์โหลดเว็บ metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
