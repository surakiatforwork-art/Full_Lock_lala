# Full Lock v0.1.41

- ดูแลแจ้งเตือนงานของ Driver อัตโนมัติ ให้ค้างไม่เกิน 15 รายการโดยลบงานเก่าสุด ไม่มีสวิตช์ตั้งค่า
- ลบเฉพาะแพ็กเกจ Driver และรูปแบบแจ้งเตือนงานที่ยืนยันได้ ไม่ลบประกาศ GPS แจ้งเตือนค้าง หัวสรุปกลุ่ม หรือแจ้งเตือนแอปอื่น
- ยกเว้นงานที่กำลังเปิด ตรวจข้อมูลซ้ำก่อนลบ และเก็บประวัติงานเก่าที่เพิ่งพบก่อนลบ

## การตรวจสอบและข้อจำกัด

สร้าง release และตรวจลายเซ็นทางการผ่าน 16 จุดตรวจตัวคัดเลือกรายการ และ 11 จุดตรวจบริการด้วย snapshot จำลอง โดยสกัดคำสั่งลบแทนการลบแจ้งเตือนจริง ครอบคลุมการเก็บล่าสุด 15 งาน แพ็กเกจอื่น ประกาศ GPS หัวสรุป ไม่อนุญาตให้ลบ รายการกำลังเปิด รหัสแจ้งเตือนที่ถูกใช้ใหม่ และบริการไม่เชื่อมต่อ

ทำงานทั้งโหมดอ่านแจ้งเตือนและรูทโดยไม่ต้องเริ่มเปิดงานอัตโนมัติ เมื่อแจ้งเตือนถูกลบจะล้างคำสั่งเปิดที่เก็บไว้ของรายการนั้นและให้รายการปุ่มลอยแสดงสถานะตามการลบของระบบ ไม่มีการรับประกันว่า Driver จะส่งแจ้งเตือนทุกกรณี และระบบนี้ไม่ทำให้เกิดแจ้งเตือนที่ Driver ไม่ได้สร้าง ยังไม่ได้ทดสอบเพดานแจ้งเตือนกับ Driver จริง

ระบบสมาชิกยังไม่รวมในรุ่นนี้

เผยแพร่เฉพาะ APK เต็มรวมส่วนเสริม ไฟล์ดาวน์โหลด metadata/checksum และบันทึกรุ่น ไม่เผยแพร่ซอร์ส Android/รูท/Xposed ใหม่ ซอร์ส Android สาธารณะใน repo ไม่ใช่ซอร์สสำหรับสร้าง APK นี้ ไม่มี Driver APK, session, token, ภาพจากเครื่องทดสอบ หรือกุญแจลงนามในไฟล์ที่เผยแพร่

Full Lock เป็นเครื่องมืออิสระ ไม่ใช่ผลิตภัณฑ์หรือการรับรองโดย Lalamove
